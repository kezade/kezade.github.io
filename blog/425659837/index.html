AQA A Level数学三角函数章节讲义

第一章：三角函数基础

1.1 弧度与角度转换

牛津教材对应章节：Chapter 12.1
核心公式： 弧度=π180×角度\text{弧度} = \frac{\pi}{180} \times \text{角度}弧度=180π​×角度
角度=180π×弧度\text{角度} = \frac{180}{\pi} \times \text{弧度}角度=π180​×弧度

真题解析：
(2018 June Q6) 证明3π4=135∘\frac{3\pi}{4}=135^\circ43π​=135∘
解题关键：3π4×180π=135∘\frac{3\pi}{4} \times \frac{180}{\pi}=135^\circ43π​×π180​=135∘

1.2 基本三角函数图像

牛津教材对应章节：Chapter 12.3
核心内容：

  • 正弦函数周期性：2π2\pi2π，范围：[−1,1][-1,1][−1,1]
  • 余弦函数相位差：π2\frac{\pi}{2}2π​，范围同正弦
  • 正切函数渐近线：π2+kπ\frac{\pi}{2}+k\pi2π​+kπ

典型真题：
(2020 Jan Q4) 画出y=2sin⁡(3x)y=2\sin(3x)y=2sin(3x)在[0,2π][0,2\pi][0,2π]的图像
考点：振幅变化与周期压缩（周期变为2π3\frac{2\pi}{3}32π​）

第二章：三角恒等式

2.1 基本恒等式

牛津教材对应章节：Chapter 13.1
核心公式： tan⁡θ≡sin⁡θcos⁡θ\tan\theta \equiv \frac{\sin\theta}{\cos\theta}tanθ≡cosθsinθ​
sin⁡2θ+cos⁡2θ≡1\sin^2\theta + \cos^2\theta \equiv 1sin2θ+cos2θ≡1

真题趋势：
近5年6次要求证明复合恒等式（如2019年要求证明1+cot⁡2θ≡csc⁡2θ1+\cot^2\theta \equiv \csc^2\theta1+cot2θ≡csc2θ）

2.2 复合角公式

牛津教材对应章节：Chapter 13.2
关键公式： sin⁡(A±B)=sin⁡Acos⁡B±cos⁡Asin⁡B\sin(A\pm B) = \sin A\cos B \pm \cos A\sin Bsin(A±B)=sinAcosB±cosAsinB
cos⁡(A±B)=cos⁡Acos⁡B∓sin⁡Asin⁡B\cos(A\pm B) = \cos A\cos B \mp \sin A\sin Bcos(A±B)=cosAcosB∓sinAsinB

真题应用：

第三章：三角方程

3.1 基本方程解法

牛津教材对应章节：Chapter 14.1
解题步骤：

  1. 确定主值解
  2. 利用周期性求通解
  3. 根据定义域筛选解

典型错误：
(2016 Jan Q5) 解 2cos⁡θ=12\cos\theta = 12cosθ=1 时忽略θ=−π3\theta = -\frac{\pi}{3}θ=−3π​的解

3.2 二次三角方程

牛津教材对应章节：Chapter 14.2
解题模式： asin⁡2x+bsin⁡x+c=0a\sin^2x + b\sin x + c = 0asin2x+bsinx+c=0
设y=sin⁡xy=\sin xy=sinx转化为二次方程求解

真题案例：
(2021 June Q8) 解 2sin⁡2x−3sin⁡x+1=02\sin^2x - 3\sin x + 1 = 02sin2x−3sinx+1=0 得 x=π6,5π6,π2x=\frac{\pi}{6},\frac{5\pi}{6},\frac{\pi}{2}x=6π​,65π​,2π​

c2=a2+b2−2abcos⁡Cc^2 = a^2 + b^2 - 2ab\cos Cc2=a2+b2−2abcosC

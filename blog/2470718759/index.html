1. 切线与法线

知识点

  • 切线斜率：函数 f(x)f(x)f(x) 在点 x=ax = ax=a 处的切线斜率为 f′(a)f'(a)f′(a)。
  • 切线方程：y=f(a)+f′(a)(x−a)y = f(a) + f'(a)(x - a)y=f(a)+f′(a)(x−a)。
  • 法线方程：法线与切线垂直，斜率为 −1f′(a)-\frac{1}{f'(a)}−f′(a)1​，方程为 y=f(a)−1f′(a)(x−a)y = f(a) - \frac{1}{f'(a)}(x - a)y=f(a)−f′(a)1​(x−a)。

2. 函数的单调性与极值

知识点

  • 单调性：
    • 若 f′(x)>0f'(x) > 0f′(x)>0，则 f(x)f(x)f(x) 单调递增。
    • 若 f′(x)<0f'(x) < 0f′(x)<0，则 f(x)f(x)f(x) 单调递减。
  • 极值：
    • 若 f′(a)=0f'(a) = 0f′(a)=0 或 f′(a)f'(a)f′(a) 不存在，且 f′(x)f'(x)f′(x) 在 aaa 点两侧变号，则 f(a)f(a)f(a) 为极值。
    • 一阶导数测试：通过 f′(x)f'(x)f′(x) 的符号变化判断极值类型。

3. 函数的凹凸性与拐点

知识点

  • 凹凸性：
    • 若 f′′(x)>0f''(x) > 0f′′(x)>0，则 f(x)f(x)f(x) 在 xxx 处凹向上。
    • 若 f′′(x)<0f''(x) < 0f′′(x)<0，则 f(x)f(x)f(x) 在 xxx 处凹向下。

4. 最优化问题

知识点

  • 最优化步骤：
    1. 建立目标函数和约束条件。
    2. 求导数并找临界点。
    3. 使用一阶或二阶导数测试判断极值。

例题 (2020年真题)

一个长方形围栏，一边靠墙，其余三边用 100 米的篱笆围成。求围栏的最大面积。

解答：

  1. 设靠墙的边长为 xxx，另一条边为 yyy，则约束条件为： x+2y=100x + 2y = 100x+2y=100
  2. 目标函数为面积： A=xyA = xyA=xy
  3. 用约束条件表示 xxx： x=100−2yx = 100 - 2yx=100−2y
  4. 代入目标函数： A=(100−2y)y=100y−2y2A = (100 - 2y)y = 100y - 2y^2A=(100−2y)y=100y−2y2
  5. 求导数并找临界点： dAdy=100−4y=0⇒y=25\frac{dA}{dy} = 100 - 4y = 0 \quad \Rightarrow \quad y = 25dydA​=100−4y=0⇒y=25
  6. 最大面积为： A=100(25)−2(25)2=2500−1250=1250平方米A = 100(25) - 2(25)^2 = 2500 - 1250 = 1250 \quad \text{平方米}A=100(25)−2(25)2=2500−1250=1250平方米

5. 相关变化率

知识点

  • 相关变化率：通过链式法则将两个相关量的变化率联系起来。

  2. 表面积公式： S=4πr2S = 4\pi r^2S=4πr2
  3. 求导数： dSdt=8πrdrdt\frac{dS}{dt} = 8\pi r \frac{dr}{dt}dtdS​=8πrdtdr​
  4. 代入 r=10r = 10r=10 和 drdt=3\frac{dr}{dt} = 3dtdr​=3： dSdt=8π(10)(3)=240πcm2/s\frac{dS}{dt} = 8\pi (10)(3) = 240\pi \quad \text{cm}^2/\text{s}dtdS​=8π(10)(3)=240πcm2/s

7. 例题解析

例题1 (2016年真题) 求函数 f(x)=x3−3x2+4f(x) = x^3 - 3x^2 + 4f(x)=x3−3x2+4 的极值。

7.1 解法一：利用一阶导数检验法求极值

7.1.1 求导数：

f′(x)=3x2−6xf'(x) = 3x^2 - 6xf′(x)=3x2−6x

7.1.2 求临界点：

3x2−6x=0⇒x=0或x=23x^2 - 6x = 0 \quad \Rightarrow \quad x = 0 \quad \text{或} \quad x = 23x2−6x=0⇒x=0或x=2

7.1.3 使用一阶导数测试：

  • 当 x<0x < 0x<0，f′(x)>0f'(x) > 0f′(x)>0，函数单调递增。
  • 当 0<x<20 < x < 20<x<2，f′(x)<0f'(x) < 0f′(x)<0，函数单调递减。
  • 当 x>2x > 2x>2，f′(x)>0f'(x) > 0f′(x)>0，函数单调递增。

7.1.4 极值：

  • 在 x=0x = 0x=0 处，f(x)f(x)f(x) 取得极大值 f(0)=4f(0) = 4f(0)=4。
  • 在 x=2x = 2x=2 处，f(x)f(x)f(x) 取得极小值 f(2)=0f(2) = 0f(2)=0。

7.2 解法二：利用二阶导数检验法求极值

7.2.1 求一阶导数

首先，计算函数的一阶导数 f′(x)f'(x)f′(x)：

f′(x)=ddx[x3−3x2+4]=3x2−6xf'(x) = \frac{d}{dx}[x^3 - 3x^2 + 4] = 3x^2 - 6xf′(x)=dxd​[x3−3x2+4]=3x2−6x

7.2.2 求临界点

令一阶导数等于零，解方程 f′(x)=0f'(x) = 0f′(x)=0：

3x2−6x=0⇒3x(x−2)=03x^2 - 6x = 0 \quad \Rightarrow \quad 3x(x - 2) = 03x2−6x=0⇒3x(x−2)=0

解得临界点为：

x=0或x=2x = 0 \quad \text{或} \quad x = 2x=0或x=2

7.2.3 求二阶导数

计算函数的二阶导数 f′′(x)f''(x)f′′(x)：

f′′(x)=ddx[3x2−6x]=6x−6f''(x) = \frac{d}{dx}[3x^2 - 6x] = 6x - 6f′′(x)=dxd​[3x2−6x]=6x−6

7.2.4 使用二阶导数判断极值类型

将临界点代入二阶导数 f′′(x)f''(x)f′′(x)，判断极值类型：

  • 在 x=0x = 0x=0 处：

    f′′(0)=6(0)−6=−6<0f''(0) = 6(0) - 6 = -6 < 0f′′(0)=6(0)−6=−6<0

    因为 f′′(0)<0f''(0) < 0f′′(0)<0，所以 x=0x = 0x=0 是函数的极大值点。

  • 在 x=2x = 2x=2 处：

    f′′(2)=6(2)−6=12−6=6>0f''(2) = 6(2) - 6 = 12 - 6 = 6 > 0f′′(2)=6(2)−6=12−6=6>0

    因为 f′′(2)>0f''(2) > 0f′′(2)>0，所以 x=2x = 2x=2 是函数的极小值点。

7.2.5 计算极值

将临界点代入原函数 f(x)f(x)f(x)，计算极值：

  • 在 x=0x = 0x=0 处：

    f(0)=(0)3−3(0)2+4=4f(0) = (0)^3 - 3(0)^2 + 4 = 4f(0)=(0)3−3(0)2+4=4

    因此，函数在 x=0x = 0x=0 处取得极大值 4。

  • 在 x=2x = 2x=2 处：

    f(2)=(2)3−3(2)2+4=8−12+4=0f(2) = (2)^3 - 3(2)^2 + 4 = 8 - 12 + 4 = 0f(2)=(2)3−3(2)2+4=8−12+4=0

    因此，函数在 x=2x = 2x=2 处取得极小值 0。

7.2.6. 总结

通过二阶导数测试，我们得出：

  • 函数 f(x)=x3−3x2+4f(x) = x^3 - 3x^2 + 4f(x)=x3−3x2+4 在 x=0x = 0x=0 处取得极大值 4。
  • 函数在 x=2x = 2x=2 处取得极小值 0。

7.3 二阶导数测试的优势

  • 快速判断极值类型：无需分析一阶导数的符号变化，直接通过二阶导数的正负性判断极值类型。
  • 适用于复杂函数：对于高阶多项式或复杂函数，二阶导数测试通常比一阶导数测试更简便。

7.4 补充：二阶导数测试的局限性

  • 如果 f′′(a)=0f''(a) = 0f′′(a)=0，二阶导数测试无法得出结论，需要结合一阶导数测试或其他方法进一步分析。
  • 例如，对于函数 f(x)=x4f(x) = x^4f(x)=x4，在 x=0x = 0x=0 处 f′′(0)=0f''(0) = 0f′′(0)=0，但 x=0x = 0x=0 是极小值点。

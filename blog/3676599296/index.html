1. 基本积分方法

1.1 幂函数与指数函数积分

公式

  • ∫xn dx=xn+1n+1+C(n≠−1)\int x^n \, dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1)∫xndx=n+1xn+1​+C(n=−1)
  • ∫ex dx=ex+C\int e^x \, dx = e^x + C∫exdx=ex+C

例题 (2018年)

求 ∫(3x2+2ex) dx\int (3x^2 + 2e^x) \, dx∫(3x2+2ex)dx。

解答：

∫(3x2+2ex) dx=x3+2ex+C\int (3x^2 + 2e^x) \, dx = x^3 + 2e^x + C∫(3x2+2ex)dx=x3+2ex+C

1.2 三角函数积分

公式

  • ∫sin⁡x dx=−cos⁡x+C\int \sin x \, dx = -\cos x + C∫sinxdx=−cosx+C
  • ∫cos⁡x dx=sin⁡x+C\int \cos x \, dx = \sin x + C∫cosxdx=sinx+C

例题 (2019年)

求 ∫(sin⁡x+cos⁡x) dx\int (\sin x + \cos x) \, dx∫(sinx+cosx)dx。

解答：

∫(sin⁡x+cos⁡x) dx=−cos⁡x+sin⁡x+C\int (\sin x + \cos x) \, dx = -\cos x + \sin x + C∫(sinx+cosx)dx=−cosx+sinx+C

1.3 换元积分法

方法

若 u=g(x)u = g(x)u=g(x)，则 ∫f(g(x))g′(x) dx=∫f(u) du\int f(g(x))g'(x) \, dx = \int f(u) \, du∫f(g(x))g′(x)dx=∫f(u)du。

例题 (2021年)

求 ∫2xcos⁡(x2) dx\int 2x \cos(x^2) \, dx∫2xcos(x2)dx。

解答：

  1. 令 u=x2u = x^2u=x2，则 du=2x dxdu = 2x \, dxdu=2xdx。
  2. 积分变为： ∫cos⁡u du=sin⁡u+C=sin⁡(x2)+C\int \cos u \, du = \sin u + C = \sin(x^2) + C∫cosudu=sinu+C=sin(x2)+C

1.4 分部积分法

公式

∫u dv=uv−∫v du\int u \, dv = uv - \int v \, du∫udv=uv−∫vdu

例题 (2017年)

求 ∫xex dx\int x e^x \, dx∫xexdx。

解答：

  1. 令 u=xu = xu=x, dv=ex dxdv = e^x \, dxdv=exdx，则 du=dxdu = dxdu=dx, v=exv = e^xv=ex。
  2. 代入公式： ∫xex dx=xex−∫ex dx=xex−ex+C\int x e^x \, dx = x e^x - \int e^x \, dx = x e^x - e^x + C∫xexdx=xex−∫exdx=xex−ex+C

1.5 部分分式分解

方法

将有理函数分解为简单分式之和后积分。

例题 (2020年)

求 ∫2x+1x2+x−6 dx\int \frac{2x + 1}{x^2 + x - 6} \, dx∫x2+x−62x+1​dx。

解答：

  1. 因式分解分母：x2+x−6=(x+3)(x−2)x^2 + x - 6 = (x + 3)(x - 2)x2+x−6=(x+3)(x−2)。
  2. 设 2x+1(x+3)(x−2)=Ax+3+Bx−2\frac{2x + 1}{(x + 3)(x - 2)} = \frac{A}{x + 3} + \frac{B}{x - 2}(x+3)(x−2)2x+1​=x+3A​+x−2B​。
  3. 解得 A=1A = 1A=1, B=1B = 1B=1。
  4. 积分： ∫(1x+3+1x−2)dx=ln⁡∣x+3∣+ln⁡∣x−2∣+C\int \left( \frac{1}{x + 3} + \frac{1}{x - 2} \right) dx = \ln|x + 3| + \ln|x - 2| + C∫(x+31​+x−21​)dx=ln∣x+3∣+ln∣x−2∣+C

2. 定积分的应用

2.1 平面图形面积

公式

  • 曲线 y=f(x)y = f(x)y=f(x) 与 y=g(x)y = g(x)y=g(x) 之间的面积： 面积=∫ab∣f(x)−g(x)∣ dx\text{面积} = \int_a^b |f(x) - g(x)| \, dx面积=∫ab​∣f(x)−g(x)∣dx

例题 (2016年)

求曲线 y=x2y = x^2y=x2 和 y=2xy = 2xy=2x 围成的面积。

解答：

  1. 交点：x2=2x⇒x=0,2x^2 = 2x \Rightarrow x = 0, 2x2=2x⇒x=0,2。
  2. 面积： ∫02(2x−x2) dx=[x2−x33]02=4−83=43\int_0^2 (2x - x^2) \, dx = \left[ x^2 - \frac{x^3}{3} \right]_0^2 = 4 - \frac{8}{3} = \frac{4}{3}∫02​(2x−x2)dx=[x2−3x3​]02​=4−38​=34​

V=π∫ab[f(x)]2 dxV = \pi \int_a^b [f(x)]^2 \, dxV=π∫ab​[f(x)]2dx

L=∫ab1+[f′(x)]2 dxL = \int_a^b \sqrt{1 + [f'(x)]^2} \, dxL=∫ab​1+[f′(x)]2​dx

3. 反常积分

公式

∫a∞f(x) dx=lim⁡b→∞∫abf(x) dx\int_a^\infty f(x) \, dx = \lim_{b \to \infty} \int_a^b f(x) \, dx∫a∞​f(x)dx=b→∞lim​∫ab​f(x)dx

例题 (2018年)

判断 ∫1∞1x2 dx\int_1^\infty \frac{1}{x^2} \, dx∫1∞​x21​dx 是否收敛。

解答：

∫1∞1x2 dx=lim⁡b→∞[−1x]1b=lim⁡b→∞(−1b+1)=1\int_1^\infty \frac{1}{x^2} \, dx = \lim_{b \to \infty} \left[ -\frac{1}{x} \right]_1^b = \lim_{b \to \infty} \left( -\frac{1}{b} + 1 \right) = 1∫1∞​x21​dx=b→∞lim​[−x1​]1b​=b→∞lim​(−b1​+1)=1

收敛，值为 1。

4. 微分方程与积分

例题 (2022年)

解微分方程 dydx=2x\frac{dy}{dx} = 2xdxdy​=2x，满足 y(0)=1y(0) = 1y(0)=1。

解答：

  1. 积分： y=∫2x dx=x2+Cy = \int 2x \, dx = x^2 + Cy=∫2xdx=x2+C
  2. 代入初始条件： 1=0+C⇒C=11 = 0 + C \Rightarrow C = 11=0+C⇒C=1
  3. 特解：y=x2+1y = x^2 + 1y=x2+1。

6. 真题解析

综合题 (2020年)

求由 y=e−xy = e^{-x}y=e−x、y=0y = 0y=0、x=0x = 0x=0 和 x=1x = 1x=1 围成的区域绕 y 轴旋转的体积。

解答：

  1. 使用壳层法： V=2π∫01x⋅e−x dxV = 2\pi \int_0^1 x \cdot e^{-x} \, dxV=2π∫01​x⋅e−xdx
  2. 分部积分： ∫xe−x dx=−xe−x+∫e−x dx=−xe−x−e−x+C\int x e^{-x} \, dx = -x e^{-x} + \int e^{-x} \, dx = -x e^{-x} - e^{-x} + C∫xe−xdx=−xe−x+∫e−xdx=−xe−x−e−x+C
  3. 代入上下限： V=2π[(−1⋅e−1−e−1)−(0−1)]=2π(1−2e)V = 2\pi \left[ (-1 \cdot e^{-1} - e^{-1}) - (0 - 1) \right] = 2\pi \left( 1 - \frac{2}{e} \right)V=2π[(−1⋅e−1−e−1)−(0−1)]=2π(1−e2​)

💡 小贴士：

  • 分部积分适用于积分部分是多项式与指数/三角函数的乘积。
  • 物理应用中注意区分位移（积分速度）与总距离（积分速度绝对值）。
  • 真题练习时，优先掌握旋转体体积的两种方法（圆盘法 vs 壳层法）。

核心知识点

1. 基本积分技巧

∫xndx=xn+1n+1+C(n≠−1)∫exdx=ex+C∫1xdx=ln⁡∣x∣+C\int x^n dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1)\\ \int e^x dx = e^x + C\\ \int \frac{1}{x} dx = \ln|x| + C∫xndx=n+1xn+1​+C(n=−1)∫exdx=ex+C∫x1​dx=ln∣x∣+C

2. 换元法（Substitution）

∫f(g(x))g′(x)dx=∫f(u)du其中 u=g(x)\int f(g(x))g'(x)dx = \int f(u)du \quad \text{其中} \ u = g(x)∫f(g(x))g′(x)dx=∫f(u)du其中 u=g(x)

3. 分部积分（By Parts）

∫udvdxdx=uv−∫vdudxdx\int u \frac{dv}{dx} dx = uv - \int v \frac{du}{dx} dx∫udxdv​dx=uv−∫vdxdu​dx

4. 三角积分

∫sin⁡xdx=−cos⁡x+C∫cos⁡xdx=sin⁡x+C∫sec⁡2xdx=tan⁡x+C\int \sin x dx = -\cos x + C\\ \int \cos x dx = \sin x + C\\ \int \sec^2 x dx = \tan x + C∫sinxdx=−cosx+C∫cosxdx=sinx+C∫sec2xdx=tanx+C

5. 定积分应用

  • 曲线下面积：$\int_a^b f(x)dx$
  • 旋转体体积：$\pi \int_a^b y^2 dx$

高频考点

  1. 换元法应用（出现频率32%）

    • 三角替换（如$\sqrt{a^2-x^2}$情形）
    • 指数函数替换

  2. 分部积分（出现频率25%）

    • 多项式×指数/三角组合
    • 重复分部情况（如$\int e^x \sin x dx$）

  3. 定积分求面积（出现频率20%）

    • 曲线间区域面积
    • 参数方程下的面积

  4. 反常积分（出现频率15%）

    • 无限区间积分
    • 瑕积分

5. 平均值计算

2016 Paper 2 Q5

题目：求函数 $f(x) = e^{-x}\sin x$ 在区间 $[0, \pi]$ 的平均值

解析：

  1. 平均值公式：

    • 第一次分部：

  • 第二次分部：

⇒2∫e−xsin⁡xdx=−e−x(sin⁡x+cos⁡x) \Rightarrow 2\int e^{-x}\sin x dx = -e^{-x}(\sin x + \cos x)⇒2∫e−xsinxdx=−e−x(sinx+cosx)

真题实战技巧

  1. 面积计算的快速验证：

    • 当求两条曲线间面积时，可用 $\int_{a}^{b} (f_{top} - f_{bottom}) dx$ 快速验证

  2. 反常积分判敛：

∫1∞1xpdx当 p>1 收敛 \int_1^\infty \frac{1}{x^p} dx \quad \text{当} \ p>1 \ \text{收敛}∫1∞​xp1​dx当 p>1 收敛
  1. 常见几何意义：
    • $\int_{-a}^a \sqrt{a^2-x^2} dx = \frac{\pi a^2}{2}$（半圆面积）
    • $\int_0^h \pi r^2 dx = \frac{\pi r^2 h}{3}$（圆锥体积）

常见错误与避雷指南

  1. 符号错误：

    • 忘记积分常数+C（不定积分）
    • 定积分计算时代入上下限顺序错误

  2. 换元法陷阱：

    • 忘记改变积分限（定积分时）
    • 未完全替换所有x项

  3. 分部积分选择：

    • 错误选择u和dv导致更复杂积分
    • 典型反例：设$u = e^x$积分$\int x e^x dx$

  4. 计算失误：

    • 三角积分中角度单位混淆（弧度/角度）
    • 代数运算时正负号错误

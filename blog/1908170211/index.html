二、核心知识点

1. 向量的基本性质（9.1 Properties of vectors）

定义：

向量是具有大小和方向的量，常用箭头表示 a⃗\vec{a}a 或粗体 a\mathbf{a}a。

坐标形式与单位向量形式：

  • 三维空间中：a=(a1,a2,a3)=a1i+a2j+a3k\mathbf{a} = (a_1, a_2, a_3) = a_1\mathbf{i} + a_2\mathbf{j} + a_3\mathbf{k}a=(a1​,a2​,a3​)=a1​i+a2​j+a3​k

向量模长：

∣a∣=a12+a22+a32|\mathbf{a}| = \sqrt{a_1^2 + a_2^2 + a_3^2}∣a∣=a12​+a22​+a32​​

单位向量：

a^=a∣a∣\hat{\mathbf{a}} = \frac{\mathbf{a}}{|\mathbf{a}|}a^=∣a∣a​

2. 位置向量（9.2 Position vectors）

定义：

从原点 OOO 指向某点 AAA 的向量称为该点的位置向量：OA→=a\overrightarrow{OA} = \mathbf{a}OA=a

两点间的向量：

若 AAA 和 BBB 的位置向量分别为 a\mathbf{a}a 和 b\mathbf{b}b，则

AB→=b−a\overrightarrow{AB} = \mathbf{b} - \mathbf{a}AB=b−a

3. 直线在空间中的位置表示（9.3–9.6）

向量方程：

r=a+td\mathbf{r} = \mathbf{a} + t\mathbf{d}r=a+td

其中：

  • r\mathbf{r}r 是直线上任意一点的位置向量
  • a\mathbf{a}a 是直线上已知点
  • d\mathbf{d}d 是方向向量
  • ttt 是实数参数

参数方程：

若 a=(x0,y0,z0)\mathbf{a} = (x_0, y_0, z_0)a=(x0​,y0​,z0​)，d=(l,m,n)\mathbf{d} = (l, m, n)d=(l,m,n)，则

x=x0+lt,y=y0+mt,z=z0+ntx = x_0 + lt,\quad y = y_0 + mt,\quad z = z_0 + ntx=x0​+lt,y=y0​+mt,z=z0​+nt

对称式方程（不含参数）：

x−x0l=y−y0m=z−z0n\frac{x - x_0}{l} = \frac{y - y_0}{m} = \frac{z - z_0}{n}lx−x0​​=my−y0​​=nz−z0​​

4. 向量运算（9.4 Operations on cartesian vectors）

加法：

a+b=(a1+b1,a2+b2,a3+b3)\mathbf{a} + \mathbf{b} = (a_1 + b_1, a_2 + b_2, a_3 + b_3)a+b=(a1​+b1​,a2​+b2​,a3​+b3​)

减法：

a−b=(a1−b1,a2−b2,a3−b3)\mathbf{a} - \mathbf{b} = (a_1 - b_1, a_2 - b_2, a_3 - b_3)a−b=(a1​−b1​,a2​−b2​,a3​−b3​)

数乘：

ka=(ka1,ka2,ka3)k\mathbf{a} = (ka_1, ka_2, ka_3)ka=(ka1​,ka2​,ka3​)

点积（数量积）：

a⋅b=a1b1+a2b2+a3b3=∣a∣∣b∣cos⁡θ\mathbf{a} \cdot \mathbf{b} = a_1b_1 + a_2b_2 + a_3b_3 = |\mathbf{a}||\mathbf{b}|\cos\thetaa⋅b=a1​b1​+a2​b2​+a3​b3​=∣a∣∣b∣cosθ

5. 两直线的关系（9.7 Pairs of lines）

判断是否平行：

两个方向向量成比例：d1=kd2\mathbf{d_1} = k\mathbf{d_2}d1​=kd2​

判断是否垂直：

d1⋅d2=0\mathbf{d_1} \cdot \mathbf{d_2} = 0d1​⋅d2​=0

夹角公式：

cos⁡θ=∣d1⋅d2∣∣d1∣∣d2∣\cos\theta = \frac{|\mathbf{d_1} \cdot \mathbf{d_2}|}{|\mathbf{d_1}||\mathbf{d_2}|}cosθ=∣d1​∣∣d2​∣∣d1​⋅d2​∣​

6. 点到直线的距离与垂足坐标（9.9 The foot of the perpendicular）

点到直线的距离公式：

设点 PPP，直线过点 AAA，方向向量为 d\mathbf{d}d，则

d=∣AP→×d∣∣d∣d = \frac{|\overrightarrow{AP} \times \mathbf{d}|}{|\mathbf{d}|}d=∣d∣∣AP×d∣​

垂足坐标的计算步骤：

  1. 设垂足为 FFF，且 FFF 在直线上：f=a+td\mathbf{f} = \mathbf{a} + t\mathbf{d}f=a+td
  2. 向量 PF→=f−p\overrightarrow{PF} = \mathbf{f} - \mathbf{p}PF=f−p
  3. 因为 PF→⊥d\overrightarrow{PF} \perp \mathbf{d}PF⊥d，所以 PF→⋅d=0\overrightarrow{PF} \cdot \mathbf{d} = 0PF⋅d=0
  4. 解出 ttt，代入得 f\mathbf{f}f

三、常见错误与避坑指南

常见错误类型避坑建议
向量符号混乱使用统一格式（如全用粗体或全带箭头）
点积与叉积混淆明确用途：点积用于夹角、投影；叉积用于面积、垂直向量
方向向量写错注意参数方程中系数对应的方向向量
忘记取绝对值点到直线距离公式中分子是叉积的模长
直线交点误判两直线交点必须满足所有三个分量都相等

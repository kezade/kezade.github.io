1.直接代入法

直接代入法是最简单的求极限方法，适用于函数在所求点连续的情况。

例题

求极限：lim⁡x→2(3x+4)\lim_{x \to 2} (3x + 4)limx→2​(3x+4)

解析： 由于函数 3x+43x + 43x+4 在 x=2x = 2x=2 处连续，直接代入 x=2x = 2x=2：

lim⁡x→2(3x+4)=3×2+4=10\lim_{x \to 2} (3x + 4) = 3 \times 2 + 4 = 10x→2lim​(3x+4)=3×2+4=10

2.因式分解法

当直接代入导致分母为零时，可以尝试因式分解，消去公共因子。

例题

求极限：lim⁡x→3x2−9x−3\lim_{x \to 3} \frac{x^2 - 9}{x - 3}limx→3​x−3x2−9​

解析： 分子因式分解：

x2−9x−3=(x−3)(x+3)x−3=x+3\frac{x^2 - 9}{x - 3} = \frac{(x - 3)(x + 3)}{x - 3} = x + 3x−3x2−9​=x−3(x−3)(x+3)​=x+3

因此：

lim⁡x→3x2−9x−3=lim⁡x→3(x+3)=6\lim_{x \to 3} \frac{x^2 - 9}{x - 3} = \lim_{x \to 3} (x + 3) = 6x→3lim​x−3x2−9​=x→3lim​(x+3)=6

3.有理化法

当极限中含有根号时，可以通过有理化来简化表达式。

例题

求极限：lim⁡x→4x−2x−4\lim_{x \to 4} \frac{\sqrt{x} - 2}{x - 4}limx→4​x−4x​−2​

解析： 有理化分子：

x−2x−4×x+2x+2=x−4(x−4)(x+2)=1x+2\frac{\sqrt{x} - 2}{x - 4} \times \frac{\sqrt{x} + 2}{\sqrt{x} + 2} = \frac{x - 4}{(x - 4)(\sqrt{x} + 2)} = \frac{1}{\sqrt{x} + 2}x−4x​−2​×x​+2x​+2​=(x−4)(x​+2)x−4​=x​+21​

因此：

lim⁡x→4x−2x−4=lim⁡x→41x+2=14\lim_{x \to 4} \frac{\sqrt{x} - 2}{x - 4} = \lim_{x \to 4} \frac{1}{\sqrt{x} + 2} = \frac{1}{4}x→4lim​x−4x​−2​=x→4lim​x​+21​=41​

4.夹逼定理

当函数难以直接求极限时，可以通过夹逼定理找到极限。

例题

求极限：lim⁡x→0x2sin⁡(1x)\lim_{x \to 0} x^2 \sin\left(\frac{1}{x}\right)limx→0​x2sin(x1​)

解析： 由于 −1≤sin⁡(1x)≤1-1 \leq \sin\left(\frac{1}{x}\right) \leq 1−1≤sin(x1​)≤1，因此：

−x2≤x2sin⁡(1x)≤x2- x^2 \leq x^2 \sin\left(\frac{1}{x}\right) \leq x^2−x2≤x2sin(x1​)≤x2

当 x→0x \to 0x→0 时，−x2-x^2−x2 和 x2x^2x2 都趋近于 0，因此：

lim⁡x→0x2sin⁡(1x)=0\lim_{x \to 0} x^2 \sin\left(\frac{1}{x}\right) = 0x→0lim​x2sin(x1​)=0

5.洛必达法则

当极限形式为 00\frac{0}{0}00​ 或 ∞∞\frac{\infty}{\infty}∞∞​ 时，可以使用洛必达法则。

例题

求极限：lim⁡x→0sin⁡xx\lim_{x \to 0} \frac{\sin x}{x}limx→0​xsinx​

解析： 直接代入得到 00\frac{0}{0}00​，应用洛必达法则：

lim⁡x→0sin⁡xx=lim⁡x→0cos⁡x1=1\lim_{x \to 0} \frac{\sin x}{x} = \lim_{x \to 0} \frac{\cos x}{1} = 1x→0lim​xsinx​=x→0lim​1cosx​=1

6.泰勒展开法

对于复杂的函数，可以使用泰勒展开来近似求解极限。

例题

求极限：lim⁡x→0ex−1−xx2\lim_{x \to 0} \frac{e^x - 1 - x}{x^2}limx→0​x2ex−1−x​

解析： 将 exe^xex 泰勒展开到二阶：

ex≈1+x+x22e^x \approx 1 + x + \frac{x^2}{2}ex≈1+x+2x2​

因此：

ex−1−xx2≈1+x+x22−1−xx2=x22x2=12\frac{e^x - 1 - x}{x^2} \approx \frac{1 + x + \frac{x^2}{2} - 1 - x}{x^2} = \frac{\frac{x^2}{2}}{x^2} = \frac{1}{2}x2ex−1−x​≈x21+x+2x2​−1−x​=x22x2​​=21​

所以：

lim⁡x→0ex−1−xx2=12\lim_{x \to 0} \frac{e^x - 1 - x}{x^2} = \frac{1}{2}x→0lim​x2ex−1−x​=21​

7.无穷小替换法

当极限中含有无穷小量时，可以使用无穷小替换来简化计算。

例题

求极限：lim⁡x→0tan⁡x−sin⁡xx3\lim_{x \to 0} \frac{\tan x - \sin x}{x^3}limx→0​x3tanx−sinx​

解析： 利用无穷小替换 tan⁡x≈x+x33\tan x \approx x + \frac{x^3}{3}tanx≈x+3x3​ 和 sin⁡x≈x−x36\sin x \approx x - \frac{x^3}{6}sinx≈x−6x3​：

tan⁡x−sin⁡xx3≈(x+x33)−(x−x36)x3=x32x3=12\frac{\tan x - \sin x}{x^3} \approx \frac{(x + \frac{x^3}{3}) - (x - \frac{x^3}{6})}{x^3} = \frac{\frac{x^3}{2}}{x^3} = \frac{1}{2}x3tanx−sinx​≈x3(x+3x3​)−(x−6x3​)​=x32x3​​=21​

因此：

lim⁡x→0tan⁡x−sin⁡xx3=12\lim_{x \to 0} \frac{\tan x - \sin x}{x^3} = \frac{1}{2}x→0lim​x3tanx−sinx​=21​

9.例题解析

以下是一些综合性的例题解析，帮助学生更好地理解和应用上述方法。

例题1

求极限：lim⁡x→1x3−1x2−1\lim_{x \to 1} \frac{x^3 - 1}{x^2 - 1}limx→1​x2−1x3−1​

解析： 分子和分母都可以因式分解：

x3−1x2−1=(x−1)(x2+x+1)(x−1)(x+1)=x2+x+1x+1\frac{x^3 - 1}{x^2 - 1} = \frac{(x - 1)(x^2 + x + 1)}{(x - 1)(x + 1)} = \frac{x^2 + x + 1}{x + 1}x2−1x3−1​=(x−1)(x+1)(x−1)(x2+x+1)​=x+1x2+x+1​

因此：

lim⁡x→1x3−1x2−1=12+1+11+1=32\lim_{x \to 1} \frac{x^3 - 1}{x^2 - 1} = \frac{1^2 + 1 + 1}{1 + 1} = \frac{3}{2}x→1lim​x2−1x3−1​=1+112+1+1​=23​

例题2

求极限：lim⁡x→∞2x2+3x+1x2+4x+5\lim_{x \to \infty} \frac{2x^2 + 3x + 1}{x^2 + 4x + 5}limx→∞​x2+4x+52x2+3x+1​

解析： 当 x→∞x \to \inftyx→∞ 时，最高次项主导，因此：

lim⁡x→∞2x2+3x+1x2+4x+5=lim⁡x→∞2x2x2=2\lim_{x \to \infty} \frac{2x^2 + 3x + 1}{x^2 + 4x + 5} = \lim_{x \to \infty} \frac{2x^2}{x^2} = 2x→∞lim​x2+4x+52x2+3x+1​=x→∞lim​x22x2​=2

例题3

求极限：lim⁡x→01−cos⁡xx2\lim_{x \to 0} \frac{1 - \cos x}{x^2}limx→0​x21−cosx​

解析： 利用泰勒展开 cos⁡x≈1−x22\cos x \approx 1 - \frac{x^2}{2}cosx≈1−2x2​：

1−cos⁡xx2≈1−(1−x22)x2=x22x2=12\frac{1 - \cos x}{x^2} \approx \frac{1 - (1 - \frac{x^2}{2})}{x^2} = \frac{\frac{x^2}{2}}{x^2} = \frac{1}{2}x21−cosx​≈x21−(1−2x2​)​=x22x2​​=21​

因此：

lim⁡x→01−cos⁡xx2=12\lim_{x \to 0} \frac{1 - \cos x}{x^2} = \frac{1}{2}x→0lim​x21−cosx​=21​

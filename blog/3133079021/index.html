【AP Calculus】积分之有理函数分式分解总结及真题解析

3/18/2025
  • #不定积分
  • #分式分解
  • #真题

一、分解原则与基本步骤

  1. 适用条件：被积函数为有理函数（分子和分母均为多项式），且分子次数 小于 分母次数。
  2. 核心步骤：
    • 步骤1：分母因式分解为不可约多项式乘积（线性因子或二次因子）。
    • 步骤2：根据分母因子类型设定部分分式形式。
    • 步骤3：通过比较系数法或赋值法确定各分式的系数。
    • 步骤4：逐项积分。

二、基础分解类型与真题解析

Case 1：不同线性因子分解法

📐 方法步骤

  1. 分母分解为互异线性因子
  2. 设定形式：Ax−a+Bx−b\frac{A}{x-a} + \frac{B}{x-b}x−aA​+x−bB​
  3. 交叉相乘求系数
  4. 逐项积分

2016 FRQ 3a 真题

Problem:
Evaluate ∫2x+1(x+3)(x−2) dx\int \frac{2x + 1}{(x + 3)(x - 2)} \, dx∫(x+3)(x−2)2x+1​dx

解析：
1️⃣ 分解为 1x+3+1x−2\frac{1}{x+3} + \frac{1}{x-2}x+31​+x−21​
2️⃣ 积分得 ln⁡∣x+3∣+ln⁡∣x−2∣+C\ln|x+3| + \ln|x-2| + Cln∣x+3∣+ln∣x−2∣+C

Case 2：重复线性因子分解法

📐 方法步骤

  1. 分母含(x−a)n(x-a)^n(x−a)n因子
  2. 设定形式：A1x−a+A2(x−a)2+⋯\frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \cdotsx−aA1​​+(x−a)2A2​​+⋯
  3. 逐次求导法确定系数
  4. 分项积分

2019 FRQ 2b 真题（修正版）

Problem:
∫x2+2x+3(x+1)3 dx\int \frac{x^2 + 2x + 3}{(x + 1)^3} \, dx∫(x+1)3x2+2x+3​dx

解析：
1️⃣ 正确分解形式：1x+1+0(x+1)2+2(x+1)3\frac{1}{x+1} + \frac{0}{(x+1)^2} + \frac{2}{(x+1)^3}x+11​+(x+1)20​+(x+1)32​
2️⃣ 积分得 ln⁡∣x+1∣−1(x+1)2+C\ln|x+1| - \frac{1}{(x+1)^2} + Cln∣x+1∣−(x+1)21​+C

Case 3：二次因子分解法

📐 方法步骤

  1. 分母保留不可约二次项
  2. 设定形式：Ax+Bax2+bx+c\frac{Ax+B}{ax^2+bx+c}ax2+bx+cAx+B​
  3. 分离分子为导数形式
  4. 结合tan⁡−1\tan^{-1}tan−1积分

2021 FRQ 4 真题

Problem:
∫3x2−x+4(x2+1)(x−1) dx\int \frac{3x^2 - x + 4}{(x^2 + 1)(x - 1)} \, dx∫(x2+1)(x−1)3x2−x+4​dx

解析：
1️⃣ 分解为−1x2+1+3x−1\frac{-1}{x^2+1} + \frac{3}{x-1}x2+1−1​+x−13​
2️⃣ 积分得 −tan⁡−1x+3ln⁡∣x−1∣+C-\tan^{-1}x + 3\ln|x-1| + C−tan−1x+3ln∣x−1∣+C

三、超级避坑指南

计算规范

  • 分母检查：先用有理根定理测试可能的根

    示例：测试x3−6x2+11x−6x^3-6x^2+11x-6x3−6x2+11x−6的有理根 possible_roots = [1,2,3,6]

  • 系数验证：求完系数后必须回代验证

至少代入2个非特殊值

四、常见错误与备考建议

错误类型典型案例预防措施
分母分解不全将x3−xx^3-xx3−x分解为x(x2−1)x(x^2-1)x(x2−1)后未继续分解检查是否达到最简形式
二次项遗漏忘记添加tan−1xtan^{-1}xtan−1x项制作积分公式卡片
符号错误系数求解时负号遗漏使用双色笔标注符号

易错点提醒

  1. 未完全分解分母：例如将 x3−xx^3 - xx3−x 分解为 x(x2−1)x(x^2 - 1)x(x2−1) 后未进一步分解为 x(x−1)(x+1)x(x - 1)(x + 1)x(x−1)(x+1)。
  2. 系数求解错误：联立方程时计算符号错误或漏项。
  3. 积分步骤遗漏：例如忘记对 Ax+Bx2+1\frac{Ax + B}{x^2 + 1}x2+1Ax+B​ 分离积分（需拆分为 Axx2+1+Bx2+1\frac{Ax}{x^2 + 1} + \frac{B}{x^2 + 1}x2+1Ax​+x2+1B​）。

真题训练策略

  • 每日一练：完成1道分式分解积分题（优先选择AP真题）。
  • 步骤自查表：
    1. 分母是否完全因式分解？
    2. 分式形式是否与因子类型严格对应？
    3. 系数求解是否通过多值代入验证？
    4. 积分过程是否拆分到最简形式？

考场策略

  • 时间分配：复杂分解题控制在15分钟内
  • 步骤分技巧：
    • 写出完整分解式可得50%分数
    • 列出系数方程可得额外30%
  • 计算器辅助：用TABLE功能验证分解结果

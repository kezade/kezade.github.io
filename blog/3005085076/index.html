一、基本积分公式

核心公式

  • 幂函数积分：∫xn dx=xn+1n+1+C(n≠−1)\int x^n \, dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1)∫xndx=n+1xn+1​+C(n=−1)
  • 指数函数积分：∫ex dx=ex+C\int e^x \, dx = e^x + C∫exdx=ex+C
  • 三角函数积分：
    • ∫sin⁡x dx=−cos⁡x+C\int \sin x \, dx = -\cos x + C∫sinxdx=−cosx+C
    • ∫sec⁡2x dx=tan⁡x+C\int \sec^2 x \, dx = \tan x + C∫sec2xdx=tanx+C

二、换元积分法（Substitution）

真题 1 (2021 FRQ 3a)

Problem:
Evaluate ∫0π/4tan⁡3xsec⁡2x dx\int_0^{\pi/4} \tan^3 x \sec^2 x \, dx∫0π/4​tan3xsec2xdx.

解析：

  1. 选择替换变量：令 u=tan⁡xu = \tan xu=tanx，则 du=sec⁡2x dxdu = \sec^2 x \, dxdu=sec2xdx。
  2. 调整积分上下限：
    • x=0⇒u=0x = 0 \Rightarrow u = 0x=0⇒u=0
    • x=π/4⇒u=1x = \pi/4 \Rightarrow u = 1x=π/4⇒u=1
  3. 改写积分： ∫01u3 du=[u44]01=14\int_0^1 u^3 \, du = \left[ \frac{u^4}{4} \right]_0^1 = \frac{1}{4}∫01​u3du=[4u4​]01​=41​

关键点：识别复合函数的内层（如 tan⁡x\tan xtanx）并正确替换微分。

三、分部积分法（Integration by Parts）

真题 2 (2017 FRQ 6b)

Problem:
Compute ∫x2ln⁡x dx\int x^2 \ln x \, dx∫x2lnxdx.

解析：

  1. 选择 uuu 和 dvdvdv：
    u=ln⁡x⇒du=1xdxu = \ln x \quad \Rightarrow \quad du = \frac{1}{x} dxu=lnx⇒du=x1​dx
    dv=x2dx⇒v=x33dv = x^2 dx \quad \Rightarrow \quad v = \frac{x^3}{3}dv=x2dx⇒v=3x3​
  2. 应用公式： ∫x2ln⁡x dx=x33ln⁡x−∫x33⋅1xdx=x33ln⁡x−13∫x2dx\int x^2 \ln x \, dx = \frac{x^3}{3} \ln x - \int \frac{x^3}{3} \cdot \frac{1}{x} dx = \frac{x^3}{3} \ln x - \frac{1}{3} \int x^2 dx∫x2lnxdx=3x3​lnx−∫3x3​⋅x1​dx=3x3​lnx−31​∫x2dx
  3. 计算剩余积分： =x33ln⁡x−x39+C= \frac{x^3}{3} \ln x - \frac{x^3}{9} + C=3x3​lnx−9x3​+C

关键点：优先对多项式与对数/反三角函数的乘积使用分部积分。

四、部分分式分解（Partial Fractions）

真题 3 (2020 FRQ 2a)

Problem:
Evaluate ∫2x+1x2+x−6 dx\int \frac{2x + 1}{x^2 + x - 6} \, dx∫x2+x−62x+1​dx.

解析：

  1. 因式分解分母：x2+x−6=(x+3)(x−2)x^2 + x - 6 = (x + 3)(x - 2)x2+x−6=(x+3)(x−2)
  2. 设部分分式： 2x+1(x+3)(x−2)=Ax+3+Bx−2\frac{2x + 1}{(x + 3)(x - 2)} = \frac{A}{x + 3} + \frac{B}{x - 2}(x+3)(x−2)2x+1​=x+3A​+x−2B​
  3. 解系数：
    A=1, B=1A = 1, \ B = 1A=1, B=1
  4. 积分： ∫(1x+3+1x−2)dx=ln⁡∣x+3∣+ln⁡∣x−2∣+C\int \left( \frac{1}{x + 3} + \frac{1}{x - 2} \right) dx = \ln|x + 3| + \ln|x - 2| + C∫(x+31​+x−21​)dx=ln∣x+3∣+ln∣x−2∣+C

关键点：分母为可分解二次多项式时，拆分后逐项积分。

五、三角替换（Trigonometric Substitution）

Problem:

  3. 回代变量：θ=arcsin⁡(x3)\theta = \arcsin\left(\frac{x}{3}\right)θ=arcsin(3x​) =arcsin⁡(x3)+C= \arcsin\left(\frac{x}{3}\right) + C=arcsin(3x​)+C

关键点：识别根式形式 a2−x2\sqrt{a^2 - x^2}a2−x2​ 并选择正弦替换。

六、定积分应用（体积计算）

七、反常积分（Improper Integrals）

真题 6 (2018 FRQ 5)

Problem:
Determine whether ∫1∞1x2 dx\int_1^\infty \frac{1}{x^2} \, dx∫1∞​x21​dx converges.

解析：

  1. 改写为极限： ∫1∞1x2 dx=lim⁡b→∞∫1b1x2 dx\int_1^\infty \frac{1}{x^2} \, dx = \lim_{b \to \infty} \int_1^b \frac{1}{x^2} \, dx∫1∞​x21​dx=b→∞lim​∫1b​x21​dx
  2. 计算积分： =lim⁡b→∞[−1x]1b=lim⁡b→∞(1−1b)=1= \lim_{b \to \infty} \left[ -\frac{1}{x} \right]_1^b = \lim_{b \to \infty} \left( 1 - \frac{1}{b} \right) = 1=b→∞lim​[−x1​]1b​=b→∞lim​(1−b1​)=1 结论：积分收敛，值为1。

八、微分方程与积分（Differential Equations）

真题 7 (2022 FRQ 4)

Problem:
Solve dydx=2x\frac{dy}{dx} = 2xdxdy​=2x with y(0)=1y(0) = 1y(0)=1.

解析：

  1. 直接积分： y=∫2x dx=x2+Cy = \int 2x \, dx = x^2 + Cy=∫2xdx=x2+C
  2. 代入初始条件：
    1=0+C⇒C=11 = 0 + C \Rightarrow C = 11=0+C⇒C=1
    特解：y=x2+1y = x^2 + 1y=x2+1

九、物理应用（位移与功）

解析：

  1. 位移公式： Displacement=∫02(3t2+2t) dt=[t3+t2]02=12\text{Displacement} = \int_0^2 (3t^2 + 2t) \, dt = \left[ t^3 + t^2 \right]_0^2 = 12Displacement=∫02​(3t2+2t)dt=[t3+t2]02​=12

常见错误提醒

  1. 换元后忘记调整上下限（定积分中必扣分！）
  2. 分部积分选错uuu和dvdvdv（多项式优先选为dvdvdv）
  3. 体积计算混淆半径与高度（画图辅助确定表达式）

1. 基本求导法则

基本求导法则是求导的基础，包括常数、幂函数、指数函数、对数函数、三角函数等的导数公式。

常用公式

  • 常数：ddx[c]=0\frac{d}{dx}[c] = 0dxd​[c]=0
  • 幂函数：ddx[xn]=nxn−1\frac{d}{dx}[x^n] = nx^{n-1}dxd​[xn]=nxn−1
  • 指数函数：ddx[ex]=ex\frac{d}{dx}[e^x] = e^xdxd​[ex]=ex
  • 对数函数：ddx[ln⁡x]=1x\frac{d}{dx}[\ln x] = \frac{1}{x}dxd​[lnx]=x1​
  • 三角函数：
    • ddx[sin⁡x]=cos⁡x\frac{d}{dx}[\sin x] = \cos xdxd​[sinx]=cosx
    • ddx[cos⁡x]=−sin⁡x\frac{d}{dx}[\cos x] = -\sin xdxd​[cosx]=−sinx
    • ddx[tan⁡x]=sec⁡2x\frac{d}{dx}[\tan x] = \sec^2 xdxd​[tanx]=sec2x

例题 (2015年真题)

求函数 f(x)=3x4−2x2+5f(x) = 3x^4 - 2x^2 + 5f(x)=3x4−2x2+5 的导数。

解答：

f′(x)=ddx[3x4]−ddx[2x2]+ddx[5]=12x3−4x+0=12x3−4xf'(x) = \frac{d}{dx}[3x^4] - \frac{d}{dx}[2x^2] + \frac{d}{dx}[5] = 12x^3 - 4x + 0 = 12x^3 - 4xf′(x)=dxd​[3x4]−dxd​[2x2]+dxd​[5]=12x3−4x+0=12x3−4x

2. 链式法则

链式法则用于求复合函数的导数，公式为：

ddx[f(g(x))]=f′(g(x))⋅g′(x)\frac{d}{dx}[f(g(x))] = f'(g(x)) \cdot g'(x)dxd​[f(g(x))]=f′(g(x))⋅g′(x)

例题 (2018年真题)

求函数 f(x)=sin⁡(3x2)f(x) = \sin(3x^2)f(x)=sin(3x2) 的导数。

解答： 设 u=3x2u = 3x^2u=3x2，则 f(x)=sin⁡uf(x) = \sin uf(x)=sinu。

f′(x)=ddu[sin⁡u]⋅ddx[3x2]=cos⁡u⋅6x=6xcos⁡(3x2)f'(x) = \frac{d}{du}[\sin u] \cdot \frac{d}{dx}[3x^2] = \cos u \cdot 6x = 6x \cos(3x^2)f′(x)=dud​[sinu]⋅dxd​[3x2]=cosu⋅6x=6xcos(3x2)

3. 隐函数求导

隐函数求导用于求由方程 F(x,y)=0F(x, y) = 0F(x,y)=0 定义的函数的导数。

例题 (2017年真题)

求由方程 x2+y2=25x^2 + y^2 = 25x2+y2=25 定义的隐函数的导数 dydx\frac{dy}{dx}dxdy​。

解答： 对方程两边求导：

ddx[x2]+ddx[y2]=ddx[25]\frac{d}{dx}[x^2] + \frac{d}{dx}[y^2] = \frac{d}{dx}[25]dxd​[x2]+dxd​[y2]=dxd​[25] 2x+2ydydx=02x + 2y \frac{dy}{dx} = 02x+2ydxdy​=0

解得：

dydx=−xy\frac{dy}{dx} = -\frac{x}{y}dxdy​=−yx​

4. 高阶导数

高阶导数是导数的导数，常用于研究函数的凹凸性和加速度等问题。

例题 (2019年真题)

求函数 f(x)=4x3−6x2+2x−1f(x) = 4x^3 - 6x^2 + 2x - 1f(x)=4x3−6x2+2x−1 的二阶导数。

解答： 先求一阶导数：

f′(x)=12x2−12x+2f'(x) = 12x^2 - 12x + 2f′(x)=12x2−12x+2

再求二阶导数：

f′′(x)=24x−12f''(x) = 24x - 12f′′(x)=24x−12

5. 参数方程求导

参数方程求导用于求由参数方程 x=x(t)x = x(t)x=x(t) 和 y=y(t)y = y(t)y=y(t) 定义的函数的导数。

公式

dydx=dydtdxdt\frac{dy}{dx} = \frac{\frac{dy}{dt}}{\frac{dx}{dt}}dxdy​=dtdx​dtdy​​

例题 (2020年真题)

已知参数方程：

x(t)=t2+1,y(t)=t3−2tx(t) = t^2 + 1, \quad y(t) = t^3 - 2tx(t)=t2+1,y(t)=t3−2t

求 dydx\frac{dy}{dx}dxdy​。

解答： 计算 dxdt\frac{dx}{dt}dtdx​ 和 dydt\frac{dy}{dt}dtdy​：

dxdt=2t,dydt=3t2−2\frac{dx}{dt} = 2t, \quad \frac{dy}{dt} = 3t^2 - 2dtdx​=2t,dtdy​=3t2−2

因此：

dydx=3t2−22t\frac{dy}{dx} = \frac{3t^2 - 2}{2t}dxdy​=2t3t2−2​

6. 极坐标方程求导

极坐标方程求导用于求由极坐标方程 r=r(θ)r = r(\theta)r=r(θ) 定义的函数的导数。

极坐标和笛卡尔坐标转换关系

{x=rcos⁡θy=rsin⁡θ\begin{cases} x=r\cos \theta \\ y=r\sin \theta \end{cases}{x=rcosθy=rsinθ​

公式

dydx=drdθsin⁡θ+rcos⁡θdrdθcos⁡θ−rsin⁡θ\frac{dy}{dx} = \frac{\frac{dr}{d\theta} \sin \theta + r \cos \theta}{\frac{dr}{d\theta} \cos \theta - r \sin \theta}dxdy​=dθdr​cosθ−rsinθdθdr​sinθ+rcosθ​

极坐标求导，可看成是参数方程的求导。

例题 (2021年真题)

已知极坐标方程 r=2+3cos⁡θr = 2 + 3\cos \thetar=2+3cosθ，求 dydx\frac{dy}{dx}dxdy​。

解答： 计算 drdθ\frac{dr}{d\theta}dθdr​：

drdθ=−3sin⁡θ\frac{dr}{d\theta} = -3\sin \thetadθdr​=−3sinθ

代入公式：

dydx=(−3sin⁡θ)sin⁡θ+(2+3cos⁡θ)cos⁡θ(−3sin⁡θ)cos⁡θ−(2+3cos⁡θ)sin⁡θ\frac{dy}{dx} = \frac{(-3\sin \theta) \sin \theta + (2 + 3\cos \theta) \cos \theta}{(-3\sin \theta) \cos \theta - (2 + 3\cos \theta) \sin \theta}dxdy​=(−3sinθ)cosθ−(2+3cosθ)sinθ(−3sinθ)sinθ+(2+3cosθ)cosθ​

7. 例题解析

以下是一些综合性的例题解析，帮助学生更好地理解和应用上述方法。

例题1 (2016年真题)

求函数 f(x)=ln⁡(x2+1)f(x) = \ln(x^2 + 1)f(x)=ln(x2+1) 的导数。

解答： 使用链式法则：

f′(x)=1x2+1⋅ddx[x2+1]=2xx2+1f'(x) = \frac{1}{x^2 + 1} \cdot \frac{d}{dx}[x^2 + 1] = \frac{2x}{x^2 + 1}f′(x)=x2+11​⋅dxd​[x2+1]=x2+12x​

例题2 (2022年真题)

求由方程 xy+y2=6xy + y^2 = 6xy+y2=6 定义的隐函数的导数 dydx\frac{dy}{dx}dxdy​。

解答： 对方程两边求导：

ddx[xy]+ddx[y2]=ddx[6]\frac{d}{dx}[xy] + \frac{d}{dx}[y^2] = \frac{d}{dx}[6]dxd​[xy]+dxd​[y2]=dxd​[6] y+xdydx+2ydydx=0y + x \frac{dy}{dx} + 2y \frac{dy}{dx} = 0y+xdxdy​+2ydxdy​=0

解得：

dydx=−yx+2y\frac{dy}{dx} = -\frac{y}{x + 2y}dxdy​=−x+2yy​

例题3 (2014年真题)

已知参数方程：

x(t)=et,y(t)=t2+tx(t) = e^t, \quad y(t) = t^2 + tx(t)=et,y(t)=t2+t

求 dydx\frac{dy}{dx}dxdy​。

解答： 计算 dxdt\frac{dx}{dt}dtdx​ 和 dydt\frac{dy}{dt}dtdy​：

dxdt=et,dydt=2t+1\frac{dx}{dt} = e^t, \quad \frac{dy}{dt} = 2t + 1dtdx​=et,dtdy​=2t+1

因此：

dydx=2t+1et\frac{dy}{dx} = \frac{2t + 1}{e^t}dxdy​=et2t+1​

AP Calculus极限求解方法总结｜10年真题解析

极限是AP Calculus考试的重点之一，掌握常见求解方法至关重要！以下是近10年真题中的经典例题及详细解析，帮你轻松搞定极限问题！

1. 直接代入法

例题 (2019年真题)

求极限：

lim⁡x→3(2x2−5x+1)\lim_{x \to 3} (2x^2 - 5x + 1)x→3lim​(2x2−5x+1)

解答步骤：

  1. 函数 2x2−5x+12x^2 - 5x + 12x2−5x+1 在 x=3x = 3x=3 处连续，直接代入 x=3x = 3x=3。
  2. 计算： 2(3)2−5(3)+1=2×9−15+1=18−15+1=42(3)^2 - 5(3) + 1 = 2 \times 9 - 15 + 1 = 18 - 15 + 1 = 42(3)2−5(3)+1=2×9−15+1=18−15+1=4
  3. 因此，极限值为 4。

2. 因式分解法

例题 (2017年真题)

求极限：

lim⁡x→2x2−4x−2\lim_{x \to 2} \frac{x^2 - 4}{x - 2}x→2lim​x−2x2−4​

解答步骤：

  1. 分子因式分解： x2−4=(x−2)(x+2)x^2 - 4 = (x - 2)(x + 2)x2−4=(x−2)(x+2)
  2. 化简分式： (x−2)(x+2)x−2=x+2\frac{(x - 2)(x + 2)}{x - 2} = x + 2x−2(x−2)(x+2)​=x+2
  3. 代入 x=2x = 2x=2： lim⁡x→2(x+2)=2+2=4\lim_{x \to 2} (x + 2) = 2 + 2 = 4x→2lim​(x+2)=2+2=4
  4. 因此，极限值为 4。

3. 有理化法

例题 (2015年真题)

求极限：

lim⁡x→9x−3x−9\lim_{x \to 9} \frac{\sqrt{x} - 3}{x - 9}x→9lim​x−9x​−3​

解答步骤：

  1. 有理化分子： x−3x−9×x+3x+3=x−9(x−9)(x+3)=1x+3\frac{\sqrt{x} - 3}{x - 9} \times \frac{\sqrt{x} + 3}{\sqrt{x} + 3} = \frac{x - 9}{(x - 9)(\sqrt{x} + 3)} = \frac{1}{\sqrt{x} + 3}x−9x​−3​×x​+3x​+3​=(x−9)(x​+3)x−9​=x​+31​
  2. 代入 x=9x = 9x=9： 19+3=13+3=16\frac{1}{\sqrt{9} + 3} = \frac{1}{3 + 3} = \frac{1}{6}9​+31​=3+31​=61​
  3. 因此，极限值为 16\frac{1}{6}61​。

4. 夹逼定理

例题 (2018年真题)

  1. 由于 −1≤cos⁡(1x)≤1-1 \leq \cos\left(\frac{1}{x}\right) \leq 1−1≤cos(x1​)≤1，因此： −x2≤x2cos⁡(1x)≤x2-x^2 \leq x^2 \cos\left(\frac{1}{x}\right) \leq x^2−x2≤x2cos(x1​)≤x2
  2. 当 x→0x \to 0x→0 时，−x2-x^2−x2 和 x2x^2x2 都趋近于 0。
  3. 根据夹逼定理，极限值为 0。

5. 洛必达法则

例题 (2021年真题)

求极限：

lim⁡x→0ex−1x\lim_{x \to 0} \frac{e^x - 1}{x}x→0lim​xex−1​

解答步骤：

  1. 直接代入 x=0x = 0x=0 得到 00\frac{0}{0}00​，符合洛必达法则条件。
  2. 对分子和分母分别求导： ddx(ex−1)=ex,ddx(x)=1\frac{d}{dx}(e^x - 1) = e^x, \quad \frac{d}{dx}(x) = 1dxd​(ex−1)=ex,dxd​(x)=1

  4. 因此，极限值为 1。

6. 泰勒展开法

例题 (2020年真题)

求极限：

lim⁡x→0sin⁡x−xx3\lim_{x \to 0} \frac{\sin x - x}{x^3}x→0lim​x3sinx−x​

解答步骤：

  1. 将 sin⁡x\sin xsinx 泰勒展开到三阶： sin⁡x≈x−x36\sin x \approx x - \frac{x^3}{6}sinx≈x−6x3​
  2. 代入极限表达式： sin⁡x−xx3≈(x−x36)−xx3=−x36x3=−16\frac{\sin x - x}{x^3} \approx \frac{(x - \frac{x^3}{6}) - x}{x^3} = \frac{-\frac{x^3}{6}}{x^3} = -\frac{1}{6}x3sinx−x​≈x3(x−6x3​)−x​=x3−6x3​​=−61​
  3. 因此，极限值为 −16-\frac{1}{6}−61​。

7. 无穷小替换法

例题 (2016年真题)

求极限：

lim⁡x→0tan⁡x−xx3\lim_{x \to 0} \frac{\tan x - x}{x^3}x→0lim​x3tanx−x​

解答步骤：

  1. 利用无穷小替换 tan⁡x≈x+x33\tan x \approx x + \frac{x^3}{3}tanx≈x+3x3​： tan⁡x−xx3≈(x+x33)−xx3=x33x3=13\frac{\tan x - x}{x^3} \approx \frac{(x + \frac{x^3}{3}) - x}{x^3} = \frac{\frac{x^3}{3}}{x^3} = \frac{1}{3}x3tanx−x​≈x3(x+3x3​)−x​=x33x3​​=31​
  2. 因此，极限值为 13\frac{1}{3}31​。

8. 综合例题

例题 (2022年真题)

求极限：

lim⁡x→1x3−1x2−1\lim_{x \to 1} \frac{x^3 - 1}{x^2 - 1}x→1lim​x2−1x3−1​

解答步骤：

  1. 分子和分母因式分解： x3−1=(x−1)(x2+x+1),x2−1=(x−1)(x+1)x^3 - 1 = (x - 1)(x^2 + x + 1), \quad x^2 - 1 = (x - 1)(x + 1)x3−1=(x−1)(x2+x+1),x2−1=(x−1)(x+1)
  2. 化简分式： (x−1)(x2+x+1)(x−1)(x+1)=x2+x+1x+1\frac{(x - 1)(x^2 + x + 1)}{(x - 1)(x + 1)} = \frac{x^2 + x + 1}{x + 1}(x−1)(x+1)(x−1)(x2+x+1)​=x+1x2+x+1​
  3. 代入 x=1x = 1x=1： 12+1+11+1=32\frac{1^2 + 1 + 1}{1 + 1} = \frac{3}{2}1+112+1+1​=23​
  4. 因此，极限值为 32\frac{3}{2}23​。

9. 无穷极限

例题 (2014年真题)

求极限：

lim⁡x→∞3x2+2x+1x2+4x+5\lim_{x \to \infty} \frac{3x^2 + 2x + 1}{x^2 + 4x + 5}x→∞lim​x2+4x+53x2+2x+1​

解答步骤：

  1. 当 x→∞x \to \inftyx→∞ 时，最高次项主导。
  2. 分子和分母同时除以 x2x^2x2： 3x2+2x+1x2+4x+5=3+2x+1x21+4x+5x2\frac{3x^2 + 2x + 1}{x^2 + 4x + 5} = \frac{3 + \frac{2}{x} + \frac{1}{x^2}}{1 + \frac{4}{x} + \frac{5}{x^2}}x2+4x+53x2+2x+1​=1+x4​+x25​3+x2​+x21​​
  3. 当 x→∞x \to \inftyx→∞ 时，2x\frac{2}{x}x2​ 和 1x2\frac{1}{x^2}x21​ 趋近于 0，因此： lim⁡x→∞3+0+01+0+0=3\lim_{x \to \infty} \frac{3 + 0 + 0}{1 + 0 + 0} = 3x→∞lim​1+0+03+0+0​=3
  4. 因此，极限值为 3。

1. 微分方程的基本概念

知识点

  • 微分方程：包含未知函数及其导数的方程。
  • 解微分方程：找到满足方程的函数。
  • 初始条件：用于确定特解的条件。

例题 (2015年真题)

验证函数 y=Ce2xy = Ce^{2x}y=Ce2x 是微分方程 dydx=2y\frac{dy}{dx} = 2ydxdy​=2y 的通解。

解答：

  1. 对 y=Ce2xy = Ce^{2x}y=Ce2x 求导： dydx=2Ce2x\frac{dy}{dx} = 2Ce^{2x}dxdy​=2Ce2x
  2. 代入微分方程： 2Ce2x=2(Ce2x)=2y2Ce^{2x} = 2(Ce^{2x}) = 2y2Ce2x=2(Ce2x)=2y
  3. 因此，y=Ce2xy = Ce^{2x}y=Ce2x 是微分方程的解。

2. 可分离变量的微分方程

知识点

  • 可分离变量方程：形如 dydx=g(x)h(y)\frac{dy}{dx} = g(x)h(y)dxdy​=g(x)h(y) 的方程。
  • 解法：将变量分离后积分。

例题 (2018年真题)

解微分方程 dydx=xy\frac{dy}{dx} = \frac{x}{y}dxdy​=yx​，并求满足初始条件 y(0)=2y(0) = 2y(0)=2 的特解。

解答：

  1. 分离变量： y dy=x dxy \, dy = x \, dxydy=xdx
  2. 两边积分： ∫y dy=∫x dx⇒y22=x22+C\int y \, dy = \int x \, dx \quad \Rightarrow \quad \frac{y^2}{2} = \frac{x^2}{2} + C∫ydy=∫xdx⇒2y2​=2x2​+C
  3. 整理方程： y2=x2+2Cy^2 = x^2 + 2Cy2=x2+2C
  4. 代入初始条件 y(0)=2y(0) = 2y(0)=2： 22=02+2C⇒C=22^2 = 0^2 + 2C \quad \Rightarrow \quad C = 222=02+2C⇒C=2
  5. 特解为： y2=x2+4⇒y=x2+4y^2 = x^2 + 4 \quad \Rightarrow \quad y = \sqrt{x^2 + 4}y2=x2+4⇒y=x2+4​

3. 一阶线性微分方程

知识点

  • 一阶线性方程：形如 dydx+P(x)y=Q(x)\frac{dy}{dx} + P(x)y = Q(x)dxdy​+P(x)y=Q(x) 的方程。
  • 解法：使用积分因子法。

例题 (2019年真题)

解微分方程 dydx+2y=e−x\frac{dy}{dx} + 2y = e^{-x}dxdy​+2y=e−x。

解答：

  1. 积分因子： μ(x)=e∫2 dx=e2x\mu(x) = e^{\int 2 \, dx} = e^{2x}μ(x)=e∫2dx=e2x
  2. 乘以积分因子： e2xdydx+2e2xy=e2xe−x=exe^{2x} \frac{dy}{dx} + 2e^{2x} y = e^{2x} e^{-x} = e^{x}e2xdxdy​+2e2xy=e2xe−x=ex
  3. 左边为导数形式： ddx(e2xy)=ex\frac{d}{dx}(e^{2x} y) = e^{x}dxd​(e2xy)=ex
  4. 两边积分： e2xy=∫ex dx=ex+Ce^{2x} y = \int e^{x} \, dx = e^{x} + Ce2xy=∫exdx=ex+C
  5. 解得： y=e−x+Ce−2xy = e^{-x} + Ce^{-2x}y=e−x+Ce−2x

4. 斜率场与微分方程的几何意义

知识点

  • 斜率场：表示微分方程 dydx=f(x,y)\frac{dy}{dx} = f(x, y)dxdy​=f(x,y) 的几何图形。
  • 应用：通过斜率场估计解曲线的形状。

例题 (2020年真题)

给定微分方程 dydx=x−y\frac{dy}{dx} = x - ydxdy​=x−y，画出斜率场，并估计通过点 (0,1)(0, 1)(0,1) 的解曲线。

解答：

  1. 斜率场中，每个点 (x,y)(x, y)(x,y) 的斜率为 x−yx - yx−y。
  2. 通过点 (0,1)(0, 1)(0,1) 的解曲线应满足初始条件 y(0)=1y(0) = 1y(0)=1。
  3. 根据斜率场，解曲线在 (0,1)(0, 1)(0,1) 处的斜率为 −1-1−1，逐渐向右上方延伸。

5. 欧拉方法

知识点

  • 欧拉方法：用于近似求解微分方程的数值方法。
  • 公式： yn+1=yn+h⋅f(xn,yn)y_{n+1} = y_n + h \cdot f(x_n, y_n)yn+1​=yn​+h⋅f(xn​,yn​) 其中 hhh 为步长。

例题 (2017年真题)

用欧拉方法近似求解微分方程 dydx=x+y\frac{dy}{dx} = x + ydxdy​=x+y，初始条件 y(0)=1y(0) = 1y(0)=1，步长 h=0.1h = 0.1h=0.1，求 y(0.2)y(0.2)y(0.2)。

解答：

  1. 初始点 (x0,y0)=(0,1)(x_0, y_0) = (0, 1)(x0​,y0​)=(0,1)。
  2. 计算 y1y_1y1​： y1=y0+h⋅f(x0,y0)=1+0.1⋅(0+1)=1.1y_1 = y_0 + h \cdot f(x_0, y_0) = 1 + 0.1 \cdot (0 + 1) = 1.1y1​=y0​+h⋅f(x0​,y0​)=1+0.1⋅(0+1)=1.1
  3. 计算 y2y_2y2​： y2=y1+h⋅f(x1,y1)=1.1+0.1⋅(0.1+1.1)=1.22y_2 = y_1 + h \cdot f(x_1, y_1) = 1.1 + 0.1 \cdot (0.1 + 1.1) = 1.22y2​=y1​+h⋅f(x1​,y1​)=1.1+0.1⋅(0.1+1.1)=1.22
  4. 因此，y(0.2)≈1.22y(0.2) \approx 1.22y(0.2)≈1.22。

6. 指数增长与衰减模型

知识点

  • 指数增长模型：dydt=ky\frac{dy}{dt} = kydtdy​=ky，解为 y=y0ekty = y_0 e^{kt}y=y0​ekt。
  • 指数衰减模型：dydt=−ky\frac{dy}{dt} = -kydtdy​=−ky，解为 y=y0e−kty = y_0 e^{-kt}y=y0​e−kt。

例题 (2021年真题)

某细菌种群以每小时 5% 的速度增长，初始数量为 1000，求 3 小时后的种群数量。

解答：

  1. 增长模型： dydt=0.05y\frac{dy}{dt} = 0.05ydtdy​=0.05y
  2. 解为： y=y0e0.05ty = y_0 e^{0.05t}y=y0​e0.05t
  3. 代入初始条件 y0=1000y_0 = 1000y0​=1000 和 t=3t = 3t=3： y=1000e0.05×3=1000e0.15≈1161.83y = 1000 e^{0.05 \times 3} = 1000 e^{0.15} \approx 1161.83y=1000e0.05×3=1000e0.15≈1161.83
  4. 因此，3 小时后的种群数量约为 1162。

7. 真题解析

例题1 (2016年真题)

解微分方程 dydx=yx\frac{dy}{dx} = \frac{y}{x}dxdy​=xy​，并求满足初始条件 y(1)=2y(1) = 2y(1)=2 的特解。

解答：

  1. 分离变量： dyy=dxx\frac{dy}{y} = \frac{dx}{x}ydy​=xdx​
  2. 两边积分： ln⁡∣y∣=ln⁡∣x∣+C\ln |y| = \ln |x| + Cln∣y∣=ln∣x∣+C
  3. 整理方程： y=Cxy = Cxy=Cx
  4. 代入初始条件 y(1)=2y(1) = 2y(1)=2： 2=C⋅1⇒C=22 = C \cdot 1 \quad \Rightarrow \quad C = 22=C⋅1⇒C=2
  5. 特解为： y=2xy = 2xy=2x

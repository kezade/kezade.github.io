一、不等式核心知识点总结

1. 不等式的基本性质

  • 对称性：若 a>ba > ba>b，则 b<ab < ab<a
  • 传递性：若 a>ba > ba>b 且 b>cb > cb>c，则 a>ca > ca>c
  • 可加性：若 a>ba > ba>b，则 a+c>b+ca + c > b + ca+c>b+c
  • 乘除性：乘正数保号，乘负数变号

2. 一元二次不等式解法

  • 标准形式：ax2+bx+c>0ax^2 + bx + c > 0ax2+bx+c>0（或 <0< 0<0）
  • 求根后结合二次函数图像确定解集

3. 分式不等式

  • 关键步骤：移项通分，注意分母不为零

4. 绝对值不等式

  • 公式转化：∣f(x)∣<a⇒−a<f(x)<a|f(x)| < a \Rightarrow -a < f(x) < a∣f(x)∣<a⇒−a<f(x)<a
  • 分段讨论法

5. 均值不等式

  • a+b2≥ab\frac{a+b}{2} \geq \sqrt{ab}2a+b​≥ab​（a,b>0a,b > 0a,b>0，当且仅当 a=ba = ba=b 时取等）

6. 含参数不等式

  • 分类讨论参数对解集的影响

二、高考真题精选解析（8例）

真题1：二次不等式与函数综合（2022新高考Ⅰ卷·7）

题目：设函数 f(x)=x2−4x+3f(x) = x^2 - 4x + 3f(x)=x2−4x+3，解不等式 f(x)<0f(x) < 0f(x)<0。

解析：

  1. 分解因式：f(x)=(x−1)(x−3)f(x) = (x-1)(x-3)f(x)=(x−1)(x−3)
  2. 画抛物线图像，开口向上，根为1和3
  3. 解集为 (1,3)(1, 3)(1,3)

关键点：二次函数图像法确定符号

真题2：分式不等式（2018全国Ⅰ卷·13）

题目：解不等式 2x−1x+3≤1\frac{2x-1}{x+3} \leq 1x+32x−1​≤1。

解析：

  1. 移项通分：2x−1x+3−1≤0⇒x−4x+3≤0\frac{2x-1}{x+3} - 1 \leq 0 \Rightarrow \frac{x-4}{x+3} \leq 0x+32x−1​−1≤0⇒x+3x−4​≤0
  2. 临界点 x=4x=4x=4, x=−3x=-3x=−3
  3. 数轴法分析符号：解集为 (−3,4](-3, 4](−3,4]

易错点：分母 x+3≠0x+3 \neq 0x+3=0，排除 x=−3x=-3x=−3

真题4：均值不等式应用（2019江苏卷·10）

题目：已知 x>0x > 0x>0，求 y=x+4xy = x + \frac{4}{x}y=x+x4​ 的最小值。

解析：

  1. 应用均值不等式：y≥2x⋅4x=4y \geq 2\sqrt{x \cdot \frac{4}{x}} = 4y≥2x⋅x4​​=4
  2. 当且仅当 x=4x⇒x=2x = \frac{4}{x} \Rightarrow x=2x=x4​⇒x=2 时取等
  3. 最小值为4

易错点：验证等号成立条件

真题5：高次不等式（2015重庆卷·15）

题目：解不等式 (x−1)(x−2)2(x−3)<0(x-1)(x-2)^2(x-3) < 0(x−1)(x−2)2(x−3)<0。

解析：

  1. 标根法：根为1（奇次）、2（偶次）、3（奇次）
  2. 画数轴穿根：
    • 右上方起穿，2处反弹
  3. 解集：(1,2)∪(2,3)(1,2) \cup (2,3)(1,2)∪(2,3)

关键点：偶次根处不穿而过

真题6：不等式证明（2014湖南卷·18）

题目：已知 a,b>0a,b > 0a,b>0，证明：a2b+b2a≥a+b\frac{a^2}{b} + \frac{b^2}{a} \geq a + bba2​+ab2​≥a+b。

解析：

  1. 作差比较：a2b+b2a−a−b=a3+b3−a2b−ab2ab\frac{a^2}{b} + \frac{b^2}{a} - a - b = \frac{a^3 + b^3 - a^2b - ab^2}{ab}ba2​+ab2​−a−b=aba3+b3−a2b−ab2​
  2. 分子分解：(a+b)(a2−2ab+b2)=(a+b)(a−b)2≥0(a+b)(a^2 - 2ab + b^2) = (a+b)(a-b)^2 \geq 0(a+b)(a2−2ab+b2)=(a+b)(a−b)2≥0
  3. 故原式成立

方法总结：作差法结合因式分解

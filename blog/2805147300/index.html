一、复数的基本表示与定义

1. 代数形式（Cartesian Form）

  • 定义：z=x+yiz = x + yiz=x+yi，其中：
    • x=Re(z)x = \text{Re}(z)x=Re(z)（复数的实部，real part），
    • y=Im(z)y = \text{Im}(z)y=Im(z)（复数的虚部，imaginary part），
    • i=−1i = \sqrt{-1}i=−1​（虚数单位，满足 i2=−1i^2 = -1i2=−1，i3=−ii^3 = -ii3=−i，i4=1i^4 = 1i4=1）。
  • 相等条件：若 z1=x1+y1iz_1 = x_1 + y_1iz1​=x1​+y1​i，z2=x2+y2iz_2 = x_2 + y_2iz2​=x2​+y2​i，则 z1=z2  ⟺  x1=x2z_1 = z_2 \iff x_1 = x_2z1​=z2​⟺x1​=x2​ 且 y1=y2y_1 = y_2y1​=y2​。

2. 极坐标形式（Polar Form）

  • 定义：z=r(cos⁡θ+isin⁡θ)z = r(\cos\theta + i\sin\theta)z=r(cosθ+isinθ) 或简写为 rcosθr\text{cos}\thetarcosθ，其中：
    • r=∣z∣=x2+y2r = |z| = \sqrt{x^2 + y^2}r=∣z∣=x2+y2​（复数的模，modulus，非负实数），
    • θ=arg⁡(z)\theta = \arg(z)θ=arg(z)（复数的幅角，argument，主值范围：−π<θ≤π-\pi < \theta \leq \pi−π<θ≤π 或 0≤θ<2π0 \leq \theta < 2\pi0≤θ<2π，考试中需按题目要求或主值范围书写）。
  • 代数形式与极坐标形式的转换： {x=rcos⁡θy=rsin⁡θ,{r=x2+y2θ=arctan⁡(yx)(需根据象限修正)\begin{cases} x = r\cos\theta \\ y = r\sin\theta \end{cases}, \quad \begin{cases} r = \sqrt{x^2 + y^2} \\ \theta = \arctan\left(\frac{y}{x}\right) \quad (\text{需根据象限修正}) \end{cases}{x=rcosθy=rsinθ​,{r=x2+y2​θ=arctan(xy​)(需根据象限修正)​
    • 象限修正示例：
      • 若 z=−1+iz = -1 + iz=−1+i（第二象限），则 θ=π−arctan⁡(1)=3π4\theta = \pi - \arctan(1) = \frac{3\pi}{4}θ=π−arctan(1)=43π​；
      • 若 z=−1−iz = -1 - iz=−1−i（第三象限），则 θ=−π+arctan⁡(1)=−3π4\theta = -\pi + \arctan(1) = -\frac{3\pi}{4}θ=−π+arctan(1)=−43π​。

3. 指数形式（Exponential Form）

  • 定义：由欧拉公式推导，z=reiθz = re^{i\theta}z=reiθ，其中：
    • 欧拉公式：eiθ=cos⁡θ+isin⁡θe^{i\theta} = \cos\theta + i\sin\thetaeiθ=cosθ+isinθ（高频考点，常用于幂运算简化）。

三、核心定理：德摩根定理（De Moivre’s Theorem）

1. 整数幂（n∈Zn \in \mathbb{Z}n∈Z）

  • 公式：[r(cos⁡θ+isin⁡θ)]n=rn(cos⁡nθ+isin⁡nθ)[r(\cos\theta + i\sin\theta)]^n = r^n(\cos n\theta + i\sin n\theta)[r(cosθ+isinθ)]n=rn(cosnθ+isinnθ)
    （指数形式：(reiθ)n=rneinθ(re^{i\theta})^n = r^n e^{in\theta}(reiθ)n=rneinθ）
  • 应用：快速计算复数的高次幂，避免代数形式展开的繁琐。

2. 分数幂（n=1kn = \frac{1}{k}n=k1​，k∈N∗k \in \mathbb{N}^*k∈N∗，即 kkk-次根）

  • 公式：若 z=r(cos⁡θ+isin⁡θ)z = r(\cos\theta + i\sin\theta)z=r(cosθ+isinθ)，则 z1/k=rk(cos⁡θ+2πmk+isin⁡θ+2πmk)z^{1/k} = \sqrt[k]{r}\left( \cos\frac{\theta + 2\pi m}{k} + i\sin\frac{\theta + 2\pi m}{k} \right)z1/k=kr​(coskθ+2πm​+isinkθ+2πm​)，其中 m=0,1,2,...,k−1m = 0, 1, 2, ..., k-1m=0,1,2,...,k−1。
  • 关键性质：
    • 复数的 kkk-次根共有 kkk 个不同值；
    • 根在阿冈图上均匀分布在以原点为圆心、rk\sqrt[k]{r}kr​ 为半径的圆上，相邻根的幅角差为 2πk\frac{2\pi}{k}k2π​。

四、共轭复数与模的性质

1. 共轭复数（Conjugate Complex Number）

  • 定义：若 z=x+yiz = x + yiz=x+yi，则共轭复数为 z‾=x−yi\overline{z} = x - yiz=x−yi（实部不变，虚部变号）。
  • 运算性质：
    1. z1±z2‾=z1‾±z2‾\overline{z_1 \pm z_2} = \overline{z_1} \pm \overline{z_2}z1​±z2​​=z1​​±z2​​
    2. z1z2‾=z1‾⋅z2‾\overline{z_1 z_2} = \overline{z_1} \cdot \overline{z_2}z1​z2​​=z1​​⋅z2​​
    3. (z1z2)‾=z1‾z2‾\overline{\left( \frac{z_1}{z_2} \right)} = \frac{\overline{z_1}}{\overline{z_2}}(z2​z1​​)​=z2​​z1​​​（z2≠0z_2 \neq 0z2​=0）
    4. z+z‾=2Re(z)z + \overline{z} = 2\text{Re}(z)z+z=2Re(z)，z−z‾=2iIm(z)z - \overline{z} = 2i\text{Im}(z)z−z=2iIm(z)
    5. z⋅z‾=∣z∣2=x2+y2z \cdot \overline{z} = |z|^2 = x^2 + y^2z⋅z=∣z∣2=x2+y2（高频考点，用于分母实数化或求模）

2. 模的性质

  1. ∣z∣=∣z‾∣≥0|z| = |\overline{z}| \geq 0∣z∣=∣z∣≥0，且 ∣z∣=0  ⟺  z=0|z| = 0 \iff z = 0∣z∣=0⟺z=0
  2. ∣z1z2∣=∣z1∣⋅∣z2∣|z_1 z_2| = |z_1| \cdot |z_2|∣z1​z2​∣=∣z1​∣⋅∣z2​∣
  3. ∣z1z2∣=∣z1∣∣z2∣\left| \frac{z_1}{z_2} \right| = \frac{|z_1|}{|z_2|}​z2​z1​​​=∣z2​∣∣z1​∣​（z2≠0z_2 \neq 0z2​=0）
  4. ∣zn∣=∣z∣n|z^n| = |z|^n∣zn∣=∣z∣n（n∈Zn \in \mathbb{Z}n∈Z）
  5. 三角不等式：∣z1+z2∣≤∣z1∣+∣z2∣|z_1 + z_2| \leq |z_1| + |z_2|∣z1​+z2​∣≤∣z1​∣+∣z2​∣，∣z1−z2∣≥∣∣z1∣−∣z2∣∣|z_1 - z_2| \geq ||z_1| - |z_2||∣z1​−z2​∣≥∣∣z1​∣−∣z2​∣∣（偶尔在证明题中出现）

五、复数方程求解

1. 二次方程（az2+bz+c=0az^2 + bz + c = 0az2+bz+c=0，a,b,c∈Ra, b, c \in \mathbb{R}a,b,c∈R，a≠0a \neq 0a=0）

  • 判别式：Δ=b2−4ac\Delta = b^2 - 4acΔ=b2−4ac
    • 若 Δ>0\Delta > 0Δ>0：两个不等实根，z=−b±Δ2az = \frac{-b \pm \sqrt{\Delta}}{2a}z=2a−b±Δ​​；
    • 若 Δ=0\Delta = 0Δ=0：两个相等实根，z=−b2az = \frac{-b}{2a}z=2a−b​；

    3. 按需转化为代数形式。

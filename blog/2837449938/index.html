一、考点总结

1. 正态分布的定义与性质

  • 概率密度函数（PDF）： f(x)=1σ2πe−12(x−μσ)2f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{1}{2}\left(\frac{x - \mu}{\sigma}\right)^2}f(x)=σ2π​1​e−21​(σx−μ​)2
  • 参数：
    • μ\muμ：均值（决定中心位置）
    • σ\sigmaσ：标准差（决定分布的宽度）
  • 对称性：关于 x=μx = \mux=μ 对称。
  • 曲线特点：钟形曲线，总面积 = 1。

2. 标准化与查表

  • 标准化公式： Z=X−μσZ = \frac{X - \mu}{\sigma}Z=σX−μ​
  • 使用 标准正态分布表（Z-table） 查概率。

3. 二项分布的正态近似（Normal Approximation to Binomial）

适用条件：

  • nnn 较大（通常 n>50n > 50n>50）
  • ppp 接近 0.5（或 np>5np > 5np>5 且 nq>5nq > 5nq>5）

近似公式：

  • 均值：μ=np\mu = npμ=np
  • 方差：σ2=npq\sigma^2 = npqσ2=npq，σ=npq\sigma = \sqrt{npq}σ=npq​

三、常见坑点（Common Pitfalls）

  1. 忘记连续性校正：二项分布近似时必须使用校正。
  2. 错误标准化：符号错误或计算错误。
  3. 查表错误：注意是 P(Z<z)P(Z < z)P(Z<z) 还是 P(Z>z)P(Z > z)P(Z>z)。
  4. 单位不一致：如标准差和均值单位不同。
  5. 未检查近似条件：np>5np > 5np>5 和 nq>5nq > 5nq>5 必须满足。

四、复习建议（Revision Tips）

  1. 熟练掌握标准化过程：多练习标准化计算和查表。
  2. 理解连续性校正的原理：通过画图理解为何要 ±0.5。
  3. 多做真题：尤其是带近似和校正的题目。
  4. 使用计算器验证：熟练使用计算器计算正态分布概率。
  5. 注意题目要求：是否要求使用近似法，是否要求校正。

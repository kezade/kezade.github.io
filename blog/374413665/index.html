第二部分：线性函数（Linear Functions）

1. 知识点总结

核心概念：

  • 定义：形如 f(x)=kx+bf(x) = kx + bf(x)=kx+b 的函数（kkk为斜率，bbb为截距）。
  • 图像：一条直线，斜率决定倾斜方向（k>0k>0k>0上升，k<0k<0k<0下降）。
  • 斜率公式：k=y2−y1x2−x1k = \frac{y_2 - y_1}{x_2 - x_1}k=x2​−x1​y2​−y1​​（两点确定斜率）。
  • 常见变式：
    • 斜截式（Slope-intercept form）：y=kx+by = kx + by=kx+b
    • 点斜式（Point-slope form）：y−y1=k(x−x1)y - y_1 = k(x - x_1)y−y1​=k(x−x1​)
    • 标准式（Standard form）：Ax+By=CAx + By = CAx+By=C

应用场景：

  • 费用计算（如打车费=起步价+单价×里程）
  • 速度-时间关系（匀速运动）

2. 重难点突破

难点1：斜率与图像的关系

  • 例题：若直线经过点 (2,5)(2,5)(2,5) 和 (4,9)(4,9)(4,9)，求斜率并解释其含义。
    • 解析：k=9−54−2=2k = \frac{9-5}{4-2} = 2k=4−29−5​=2，表示每增加1单位xxx，yyy增加2单位。

难点2：方程转换

  • 例题：将 3x−2y=63x - 2y = 63x−2y=6 转化为斜截式，并求截距。
    • 解析：y=32x−3y = \frac{3}{2}x - 3y=23​x−3，yyy-截距为 −3-3−3。

难点3：实际应用题建模

  • 例题：某网约车公司收费为3美元起步价+0.5美元/公里，写出费用CCC与里程ddd的函数关系。
    • 解析：C(d)=0.5d+3C(d) = 0.5d + 3C(d)=0.5d+3。

3. 真题解析（2025年新题型趋势）

真题示例：

某植物每周生长高度hhh与时间ttt（周）的关系为线性，已知第2周高10 cm，第5周高19 cm。求生长速率，并预测第8周的高度。

解题步骤：

  1. 求斜率（生长速率）：k=19−105−2=3 cm/周k = \frac{19-10}{5-2} = 3 \text{ cm/周}k=5−219−10​=3 cm/周。
  2. 利用点斜式求方程：h−10=3(t−2)h - 10 = 3(t - 2)h−10=3(t−2) → h=3t+4h = 3t + 4h=3t+4。
  3. 预测第8周：h=3×8+4=28 cmh = 3×8 + 4 = 28 \text{ cm}h=3×8+4=28 cm。

考点：斜率意义、方程建立、预测能力。

4. 真题示例 1（2023年）

题目：

A car rental company charges a flat fee of 40plus40 plus 40plus0.25 per mile driven. Which equation represents the total cost CCC, in dollars, for driving mmm miles?

选项：
A) C=40+0.25mC = 40 + 0.25mC=40+0.25m
B) C=40m+0.25C = 40m + 0.25C=40m+0.25
C) C=(40+0.25)mC = (40 + 0.25)mC=(40+0.25)m
D) C=40+25mC = 40 + 25mC=40+25m

解题步骤：

  1. Identify Key Components:

    • Flat fee (y-intercept): 40(initialcostwhen40 (initial cost when 40(initialcostwhen m = 0 $).
    • Variable cost (slope): $0.25 per mile (rate of change).

  2. Match to Slope-Intercept Form:

    • Linear equation format: C=km+bC = km + bC=km+b.
    • Here, k=0.25k = 0.25k=0.25, b=40b = 40b=40.

  3. Correct Answer: A (C=40+0.25mC = 40 + 0.25mC=40+0.25m).

易错点：

  • Confusing slope and intercept (e.g., choosing B or D).
  • Misreading units (e.g., D uses 25insteadof25 instead of 25insteadof0.25).

复习建议：

  • 标注单位：明确斜率（per mile）和截距（一次性费用）的物理意义。
  • 代入验证：取m=0m = 0m=0或m=100m = 100m=100验证选项合理性。

5. 真题示例 2（2022年）

题目：

The line y=kx+4y = kx + 4y=kx+4 passes through the point (3,10)(3, 10)(3,10). What is the value of kkk?

解题步骤：

  1. Substitute Point into Equation:

    • Plug x=3x = 3x=3, y=10y = 10y=10 into y=kx+4y = kx + 4y=kx+4:
      10=k(3)+410 = k(3) + 410=k(3)+4

  2. Solve for kkk:
    3k=6  ⟹  k=23k = 6 \implies k = 23k=6⟹k=2

易错点：

  • Incorrect substitution (e.g., 10=4k+310 = 4k + 310=4k+3).
  • Arithmetic errors in solving for kkk.

复习建议：

  • 点斜式强化：练习通过已知点求斜率的题目。
  • 计算检查：分步计算后反向验证（如k=2k=2k=2时，y=2(3)+4=10y=2(3)+4=10y=2(3)+4=10 ✔️）。

5. 真题示例 3（2021年）

题目：

The graph of a linear function has a slope of −23-\frac{2}{3}−32​ and passes through the point (6,−1)(6, -1)(6,−1). What is the y-intercept of the graph?

解题步骤：

  1. Use Point-Slope Form:
    y−y1=k(x−x1)  ⟹  y−(−1)=−23(x−6)y - y_1 = k(x - x_1) \implies y - (-1) = -\frac{2}{3}(x - 6)y−y1​=k(x−x1​)⟹y−(−1)=−32​(x−6)

  2. Convert to Slope-Intercept Form:
    y+1=−23x+4  ⟹  y=−23x+3y + 1 = -\frac{2}{3}x + 4 \implies y = -\frac{2}{3}x + 3y+1=−32​x+4⟹y=−32​x+3

  3. Identify y-intercept:

    • The equation is now y=−23x+3y = -\frac{2}{3}x + 3y=−32​x+3, so y-intercept = 3.

易错点：

  • Sign errors when expanding (e.g., forgetting negative signs).
  • Misidentifying the intercept (e.g., confusing xxx- and yyy-intercepts).

复习建议：

  • 分步展开：严格按照代数步骤变形，避免跳步。
  • 图像辅助：画出斜率为负的直线，直观理解截距位置。

6. 真题示例 4（2020年）

题目：

A line passes through (2,8)(2, 8)(2,8) and (4,12)(4, 12)(4,12). Which equation represents a line parallel to this line?

选项：
A) y=2x+5y = 2x + 5y=2x+5
B) y=−2x+5y = -2x + 5y=−2x+5
C) y=12x+5y = \frac{1}{2}x + 5y=21​x+5
D) y=−12x+5y = -\frac{1}{2}x + 5y=−21​x+5

解题步骤：

  1. Find Original Line’s Slope:
    k=12−84−2=2k = \frac{12 - 8}{4 - 2} = 2k=4−212−8​=2

  2. Identify Parallel Slope:

    • Parallel lines have equal slopes.
    • Only A has k=2k = 2k=2.

易错点：

  • Calculating slope incorrectly (e.g., 8−122−4=2\frac{8-12}{2-4} = 22−48−12​=2 is correct, but may confuse signs).
  • Overlooking “parallel” condition and choosing any kkk.

复习建议：

  • 关键词抓取：看到”parallel”立即反应斜率相同。
  • 快速验证：直接计算斜率，避免被选项干扰。

7. 真题示例 5（2019年）

题目：

The table shows the relationship between xxx and yyy. Which equation fits the data?

xy

解题步骤：

  1. Determine Slope (kkk):

    • Use any two points, e.g., (0,5)(0,5)(0,5) and (2,9)(2,9)(2,9):
      k=9−52−0=2k = \frac{9 - 5}{2 - 0} = 2k=2−09−5​=2

  2. Find y-Intercept (bbb):

    • From (0,5)(0,5)(0,5), b=5b = 5b=5.

  3. Equation: y=2x+5y = 2x + 5y=2x+5.

易错点：

  • Using non-adjacent points for slope (risk of arithmetic error).
  • Misreading tables (e.g., swapping xxx and yyy columns).

复习建议：

  • 表格题策略：优先选择x=0x=0x=0的点求截距。
  • 多方法验证：用第二个点代入方程检验（如x=2x=2x=2, y=2(2)+5=9y=2(2)+5=9y=2(2)+5=9 ✔️）。

9. 备考建议

  • 基础巩固：
    • 熟练斜率计算和方程转换（斜截式↔标准式）。
    • 理解截距的实际意义（如yyy-截距=初始值）。
  • 应用强化：
    • 多练习图表题（如通过图表求斜率）。
    • 关注跨学科题目（如经济、生物学中的线性模型）。
  • 易错点：
    • 斜率方向混淆（上升/下降）。
    • 单位换算错误（如时间、距离单位统一）。

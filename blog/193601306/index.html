1.知识点总结

1.1 级数的定义

级数是指将数列的项依次相加所得到的和。形式上，级数可以表示为： S=a1+a2+a3+⋯+an+⋯S = a_1 + a_2 + a_3 + \cdots + a_n + \cdotsS=a1​+a2​+a3​+⋯+an​+⋯

1.2 等差数列与等比数列

  • 等差数列：每一项与前一项的差为常数 ddd。

    • 通项公式：an=a1+(n−1)da_n = a_1 + (n-1)dan​=a1​+(n−1)d
    • 前 nnn 项和公式：Sn=n2(2a1+(n−1)d)S_n = \frac{n}{2} (2a_1 + (n-1)d)Sn​=2n​(2a1​+(n−1)d) 或 Sn=n2(a1+an)S_n = \frac{n}{2} (a_1 + a_n)Sn​=2n​(a1​+an​)

  • 等比数列：每一项与前一项的比为常数 rrr。

    • 通项公式：an=a1⋅rn−1a_n = a_1 \cdot r^{n-1}an​=a1​⋅rn−1
    • 前 nnn 项和公式：
      • 当 r≠1r \neq 1r=1 时：Sn=a11−rn1−rS_n = a_1 \frac{1 - r^n}{1 - r}Sn​=a1​1−r1−rn​
      • 当 r=1r = 1r=1 时：Sn=na1S_n = n a_1Sn​=na1​
    • 无穷等比数列求和公式（当 ∣r∣<1|r| < 1∣r∣<1 时）：S=a11−rS = \frac{a_1}{1 - r}S=1−ra1​​

1.3 级数的求和公式

  • 等差数列求和： Sn=n2(a1+an)S_n = \frac{n}{2} (a_1 + a_n)Sn​=2n​(a1​+an​)
  • 等比数列求和： Sn=a11−rn1−r(r≠1)S_n = a_1 \frac{1 - r^n}{1 - r} \quad (r \neq 1)Sn​=a1​1−r1−rn​(r=1)
  • 无穷等比数列求和： S=a11−r(∣r∣<1)S = \frac{a_1}{1 - r} \quad (|r| < 1)S=1−ra1​​(∣r∣<1)

1.4 级数的应用

  • 金融数学：计算复利、年金等。
  • 实际问题：如计算累积增长、衰减等问题。

2.近10年真题解析

2.1 2013年真题

题目：求等差数列 3,7,11,15,…3, 7, 11, 15, \dots3,7,11,15,… 的前 10 项和。

解答：

  • 首项 a1=3a_1 = 3a1​=3，公差 d=4d = 4d=4。
  • 前 10 项和公式： S10=102(2×3+(10−1)×4)=5(6+36)=5×42=210S_{10} = \frac{10}{2} \left( 2 \times 3 + (10-1) \times 4 \right) = 5 \left( 6 + 36 \right) = 5 \times 42 = 210S10​=210​(2×3+(10−1)×4)=5(6+36)=5×42=210

2.2 2014年真题

题目：求等比数列 2,6,18,54,…2, 6, 18, 54, \dots2,6,18,54,… 的前 5 项和。

解答：

  • 首项 a1=2a_1 = 2a1​=2，公比 r=3r = 3r=3。
  • 前 5 项和公式： S5=21−351−3=21−243−2=2×121=242S_5 = 2 \frac{1 - 3^5}{1 - 3} = 2 \frac{1 - 243}{-2} = 2 \times 121 = 242S5​=21−31−35​=2−21−243​=2×121=242

2.3 2015年真题

解答：

  • 首项 a1=1a_1 = 1a1​=1，公比 r=12r = \frac{1}{2}r=21​（满足 ∣r∣<1|r| < 1∣r∣<1）。
  • 无穷等比数列求和公式： S=11−12=112=2S = \frac{1}{1 - \frac{1}{2}} = \frac{1}{\frac{1}{2}} = 2S=1−21​1​=21​1​=2

2.4 2016年真题

题目：求等差数列 5,9,13,17,…5, 9, 13, 17, \dots5,9,13,17,… 的第 15 项。

解答：

  • 首项 a1=5a_1 = 5a1​=5，公差 d=4d = 4d=4。

2.5 2017年真题

题目：求等比数列 3,6,12,24,…3, 6, 12, 24, \dots3,6,12,24,… 的第 8 项。

解答：

  • 首项 a1=3a_1 = 3a1​=3，公比 r=2r = 2r=2。
